[![Version](https://img.shields.io/badge/version-1.0.5-brightgreen.svg)](CHANGELOG.md)

将小说、剧本或故事改编为**即梦 / Seedance / Kling**等现代 AI 视频生成工具可直接执行的**导演级工业分镜**。

融合《逐玉》光影构图与《糯糯下山》表演剪辑，细写可见动作、空间层次和信息揭示，提供高执行力、防形变、视听同步的专业分镜产出能力。

## 核心特性

### 1. 严格的时长控制算法
- **10.0–15.0 秒黄金段落**：每一段均严格控制在 10.0–15.0 秒（含首尾段），符合主流 AI 视频工具成片规律与下游剪辑节奏。
- **杜绝碎片镜头**：单镜时长推荐一般 $\ge 2.0$ 秒（除特定爆点极速闪切外），杜绝 AI 难以渲染的超短碎镜（<1.5s）。
- **时长精确加总**：段首标题时长必须严格等于本段各镜头时长求和（一位小数），禁止靠空镜凑秒或为抢时长吞字。

### 2. AI 扩散模型防翻车工程设计
- **角色外观与服装解耦设计（分镜与美术资产并行流水线）**：提示词彻底剔除服装颜色、款式形制、花纹等静态外观词，将外观基准全权交给下游角色参考图；提示词专攻肢体动作、视线、神态表情与衣物物理受力（风动、翻卷、扯紧、湿透），杜绝提示词与参考图打架。
- **单人交替隔离正反打（A-B-A-B-A）**：强冲突镜头每镜第一句均写明 `本镜画面中仅有1人`，将对峙拆解为单人正反打，彻底根除双人同框时的融人、肢体粘连与“双胞胎”形变。
- **180° 轴线与屏幕视线锁定**：
  - 画左角色（置于画面左侧三分线）：**视线必须明确标注投向画右**；
  - 画右角色（置于画面右侧三分线）：**视线必须明确标注投向画左**；
  - 正反打对视严格锁定，彻底杜绝 AI 生成时的视线撞车。
- **严密的嘴型与闭口控制**：所有无台词镜头、画外听者镜头均显式标注“闭口”，严禁 AI 扩散模型在无对白时随意抽搐或对错嘴型。
- **手持微幅呼吸感（Handheld Breathing）**：区别于剧烈颠簸，赋予摄影机有机的微小呼吸起伏，打破纯 3D 渲染的死板僵滞。
- **转焦避坑（Rack Focus 防护）**：警示并规避单镜内大范围光学虚焦拉风箱（易致画面融化噪点），采用物理位移推进或直接切镜转移视觉重心。

### 3. 快节奏剪辑与高张力镜头语言（Pacing, Impact & Micro-acting）
不生搬硬套死板模板，而是提炼快节奏视听语言的核心推力，根据剧本有机调度：
- **截断式剪辑（Interrupted Cutting）**：台词或动作在情绪高点被突发画外暴响或外力暴力硬截断（如“我的——”尾字截断接踹门声），制造强烈的听觉冲击与剧情推背感。
- **动静急刹对撞（Extreme Motion Contrast）**：极度动态的冲击动作（如抓狂抱头、暴烈破门）紧接完全凝固的静止反应（倒吸冷气、手滑跌落、目瞪口呆），动静骤停营造强烈的心理停滞感。
- **写实生理机制微表情**：彻底淘汰“震惊、害怕”等概括词，细写到“双眼睁大瞳孔骤缩、倒吸冷气、身体一颤、双手失控滑落跌在腿上”等肌肉受惊本能。
- **情绪瞬间换挡（预期违背）**：在强刺激后打破常规恐惧套路，通过微妙眼神与面部微动瞬间从“惊魂未定”换挡为“看疯子/极度荒谬/无语”的冷幽默反差。
- **极端视点造势**：平视常规机位与贴地大仰视角（距地 0.2–0.3m 仰摄）形成强烈落差，用机位自身建立天然威压。

### 4. 摄影机五要素与公制距离规范
运镜字段必须按单行一句话串成：
```text
运镜：摄影机[起位·视角/高度·景别·距主体公制距离]看[主体]，[运动路径]；焦点[变化轨迹或稳定位置]；结束于[结束构图+停留感]
```
- 距离统一使用标准公制单位（米/m、厘米/cm），全面停用口语化模糊单位“步”。
- 运动动词规范为 9 大标准类：`推`、`拉`、`摇`、`移`、`升`、`降`、`环绕`、`固定`、`复合`。

### 5. 跨镜角色音色一致性
- 建立唯一 Voice ID（如 `V001`）与 3–5 项核心物理音质特征。
- 采用标准音色锚点：`标准资产名【V001｜基础音色描述】`，情绪（哭腔、压低等）剥离至锚点外，实现下游 TTS / 配音跨镜一致。

## 版本管理与多版本切换（支持一键回退）

本项目支持严格的**多版本并存**与**历史版本秒级回退**。在项目根目录下提供了便捷的管理工具 `scripts/version_manager.py`：

### 1. 查看所有并存版本
```bash
python scripts/version_manager.py list
```
输出示例：
```text
============================================================
📦 director-mode-fusion 版本清单
当前工作分支: master  |  当前 SKILL.md 版本: v1.0.0
============================================================
已发布版本 (可在任何时候一键切换/回退到任一版本):
  --> [当前激活] v1.0.0       feat: initial release with disruption beat profile
```

### 2. 回退到以前的历史版本（自动同步到 Antigravity）
如果需要回退到任一指定版本（例如 `v1.0.0`），只需运行：
```bash
python scripts/version_manager.py switch v1.0.0
```
* 该命令会自动将 Git 检出至该版本标签，并**自动将历史版本完整同步到 Antigravity 的配置目录**，无需手动搬运文件。
* 随时切回最新开发主干：
  ```bash
  python scripts/version_manager.py switch master
  ```

### 3. 发布新版本（自动更新文档、提交、打 Tag、推 GitHub、创建 Release）
每次修改并完善 Skill 后，运行以下单行命令即可完成一键发布：
```bash
python scripts/version_manager.py release 1.1.0 -m "优化了中全景转焦提示词，增强了雨景光影控制"
```
工具将全自动完成：
1. 更新 `SKILL.md` 的 `version` 元数据；
2. 在 `CHANGELOG.md` 中记录本次改动详情；
3. 执行 Git 提交并生成 Annotated Git Tag；
4. 推送分支与标签至 GitHub 远程；
5. 调用 GitHub CLI 创建带改动说明的 Release；
6. 自动同步至本地 Antigravity 配置目录。

## 安装与使用

### 作为 Antigravity Skill 安装
克隆或放置到用户配置目录：
```bash
git clone <repo-url> C:\Users\<Username>\.gemini\config\skills\director-mode-fusion
```
在 Antigravity 聊天中输入 `/director-mode-fusion` 或直接发送剧本/小说文本，即可触发专业分镜模式。

## 自动化格式与数值校验

项目自带完备的 Python 校验脚本，可用于交付前的硬性指标自动核验：

```bash
# 基础结构、编号、运镜五要素与时长求和校验
python scripts/validate_storyboard.py your_storyboard.md

# 分批次续写校验（如从第 31 镜、第 8 段开始）
python scripts/validate_storyboard.py your_storyboard.md --start-shot 31 --start-paragraph 8

# 音色锚点一致性核验
python scripts/validate_storyboard.py your_storyboard.md --check-voices

# 制作控制卡与参考图预算核验
python scripts/validate_storyboard.py your_storyboard.md --check-controls
```
