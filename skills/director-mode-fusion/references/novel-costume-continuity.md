# 原小说对照与分期造型

制作分镜提示词时使用。已有原小说就对照对应情节，覆盖本次所有相关角色；只有剧本时按可确认内容建立造型记录，标明小说未提供。此步骤用于决定当前镜头采用哪个角色造型，不自动增加美术资产包、图片或原著分析报告。

## 1. 素材分工与定位

- 本次剧本决定发生什么、谁在场、台词、事件顺序与揭示时机；原小说补充与该剧本相容的衣着、妆发、年龄、身份阶段和身体状态。直接以小说改编且没有剧本时，小说本身也是剧情依据。
- 按人物、地点、事件和前后状态匹配小说章节。改编可能合并、重排或删除情节，不能把剧本第几集直接对应小说第几章，也不能因小说有某套衣服就补回整场戏。
- 先查用户提供或项目中已明确关联的小说及既有设定，只读当前范围的相关章节和必要前后文。没有原著正文时不凭书名、记忆或搜索片段声称已完成核对；记录缺口并继续有依据的分镜工作。
- 同一小说有多个版本且差异影响造型时记录采用版本；无法判断的细节保留待确认，不拼成一套“原著造型”。

## 2. 造型证据与冲突处理

每条记录写清来源文件、章号/章名或可定位段落，并摘取足以定位的短句；页码不稳定时使用章节与段落位置。不编造出处。证据区分为：

| 证据 | 处理 |
| --- | --- |
| 剧本或小说明确描述 | 记录原有特征与适用情节，避免跨时期挪用 |
| 承接可确认的前一场状态 | 写明承接依据及持续范围，不把承接写成原著新描述 |
| 制作需要但原文未交代 | 标为“制作拟定”或“待设计”，不自行补出精确色彩、纹样和材质 |

剧情以剧本为准；外观先满足用户当前要求与已确认项目资产，再采用剧本的明确造型、与剧本相容的小说描述，最后才是明确标注的制作拟定。冲突要留在工作记录中：例如小说此处仍守丧，而剧本明确已经换装，就按剧本场次处理，不让两种衣着同时生效。已确认资产若缺少剧情必需的遮挡或识别特征，记录需修订项；确实影响身份或因果且无法据现有授权解决时才澄清。

原文明确的颜色、款式、饰物和穿戴方式应保存在造型记录中，不能因提示词解耦而丢失。脸部与体型基准继承同一人物/年龄阶段的既定资产，不随换衣重新设计。没有角色图时标“待制作”，不把文字证据当成图像已核验。

## 3. 哪些状态需要独立造型

- 前世/现世、幼年/成年等需要区分的阶段单独管理；同阶段若存在明确的多套衣着，再按具体用途区分。
- 守丧、寝居、礼服、朝服、婚服、军装、伪装、囚禁、带斗篷外出等，只在当前素材支持且会改变可见参考需求时建立资产，不把这些类别当成每部作品必有的清单。
- 同一套服装的短时褶皱、飘动、轻微落雪等通常写进画面和连续性记录。湿透、严重破损、持续血污或新增遮面等需跨段复现、会明显影响参考图时，建立状态变体并注明对应基础造型。
- 单独拿起斗篷、帷帽或面具不必立刻新增全套衣服。先判断它是可独立管理的穿戴件，还是已经形成需要独立参考的完整外观；穿上、取下、转交的动作与状态都要保留。
- 没有换装依据时复用当前造型。跨集、转场、封号改变、情绪变化不自动意味着换衣；明确换了衣服也不能继续用同一个泛称掩盖差异。

标准名使用“角色名-具体造型名”，多阶段需要时可用“角色名-阶段-造型名”。名称短而可辨，避免“造型1”“换装后”而无可追溯含义；已有资产不为编号整齐强行改名，维护旧名映射。单一稳定造型可保留原有裸角色名；一旦本次存在多套可见造型，就在使用位置明确区分。

## 4. 内部造型记录

| 字段 | 内容 |
| --- | --- |
| 人物/年龄阶段 | 稳定身份与阶段，区别于服装 |
| 造型资产名/基础造型 | 当前标准名；状态变体关联原套服装 |
| 剧本适用范围 | 集、场次及分镜镜号，范围随编排更新 |
| 小说出处/证据 | 文件版本、章节/段落、短摘录与证据等级 |
| 衣着与妆发 | 原文明确的特征；无依据部分留待设计 |
| 进入/退出状态 | 穿戴、脱换、遮面、污染或损坏的触发与结果 |
| 发声身份 | V-ID绑定的人物/声音阶段，换衣通常不变 |
| 参考状态 | 对应参考图或待制作项，冲突与解决依据 |

按事件顺序核对每名相关角色的时间线，标出开始、结束、恢复及复用关系，不只统计主角。无独立外观需求的功能群像可按群体造型记录。每个独立生成段都能从资产名和当前状态恢复造型，不依赖“同前”。

## 5. 写入分镜与复核

- 出场人物、画面、运镜及图片清单采用当前造型资产名。具体服装依据保留在对应资产记录，默认不在每镜重新描述；参考图尚缺时，资产名仍是需求标识，不能当作已绑定图片。
- 服饰承担剧情识别、伪装揭示、遮挡、抓扯、交接或动作限制时，画面写出必要特征与变化；不因“外观交给参考图”而删掉这些因果信息，也不扩写无关装饰。
- 换装发生在明确转场或时间省略内时，下一场使用新造型并记录依据，不额外编一场换衣戏；原文要求现场穿戴/脱换时，保留动作过程。
- 同一人物不同服装通常共用发声身份与V-ID。声音字段采用发声身份名，在锚点后标注当前造型；年龄造成声音阶段变化时再分配对应身份，见 [角色音色分析与跨镜绑定](voice-consistency.md)。
- 同段出现同一人物两套造型时分别计入图片需求，遵守9张总预算。检查跨镜发饰、穿戴件、伤污和持物不无故消失，恢复状态有换装、清理或时间变化依据。

结构脚本不验证小说匹配、造型证据或分期正确性；必须语义复核。默认成品仍只有段落分镜，不增加“小说依据”或“服装说明”固定字段。
