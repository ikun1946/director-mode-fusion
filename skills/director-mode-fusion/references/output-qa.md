# 成品格式与质检

## 固定格式

每个段落按以下顺序输出；不添加独立镜间解释、导演分析或检查结果。复杂项目可在内部使用制作控制卡，但默认不把它写进交付；控制卡规则见 [制作控制与执行策略](production-controls.md)，角色音色规则见 [角色音色分析与跨镜绑定](voice-consistency.md)。

1. `段落N｜总时长：X.Xs`
2. `场景：具体地点 具体时间 内/外`
3. `本段场景布局：本段所需地标、关键陈设、通道及相互关系`（只写环境，独立可读，不强制字数或物件数量）
4. `出场人物：姓名、姓名`（无符合条件者写“无”）
5. `本段统一光影/质感：只描述环境和成像`（起始场景的光源与照射关系，按需补充质感和景深）
6. 逐镜重复：`镜N｜X.Xs｜景别/视角/构图`、`画面：`、`台词/声音：`、`运镜：`。
7. 有对白的发声者在 `台词/声音` 中使用 `发声身份标准名【V001｜基础音色描述】`；视觉造型名不同时在锚点后注明当前造型，同一声音阶段跨镜复用同一 V-ID 和基础描述，临时情绪写在锚点外。
8. 环境光确实变化时，允许在相应镜头“画面”后补 `本镜光影：`，不写人物。
9. 同场局部取景或站位变化不重写场景字段。一段内真实切换独立地点、时间或内外景，在新场首镜之前依次写 `场景：新地点 时间 内/外`、`本段场景布局：新场必要布局`、`本场光影/质感：新场环境与成像`。换场重建作用域，布局与本场光影作用至下一换场；不得继承上一场光源。不在段首写双场景箭头，不命名“场景1到场景2”。同一连续镜头穿过同一场所的相连区域，可用具体上位场所名，在画面中按门口和路径交代区域变化；不把不连续时空冒充相连空间。
10. 两段之间用单独一行 `@`；镜号全程连续。新作品默认段落1、镜1；续作沿用已有编号。

场景名以可复用完整空间为单位，必要层级用半角短横线 `-` 分隔，例如 `场景：皇宫-养心殿 夜 内`；不强制三层，不混用间隔号、斜杠或长横线。卧榻前、窗边、门口等同场局部只写画面/运镜，不另建场景资产；细分旧名统一映射到标准场景名。时间与内外景不并入基础地点名，复用与必要拆分见制作控制2.3。

运镜字段写法（SD 单行摄影机指令）：

```text
运镜：摄影机[起位·视角/高度·景别·距主体公制距离]看[主体]，[运动路径]；焦点[变化轨迹或稳定位置]；结束于[结束构图+硬切/最终结束]
```

五要素按此顺序串成一句：起位（含位置/机高与视角/景别/距主体公制距离，摄影机定位不用“步”计量）→ 观察/跟随目标 → 运动路径（推/拉/摇/移/升/降/环绕/固定/复合九类动词之一，可带缓入缓出等速度曲线）→ 焦点变化或稳定焦点 → 结束构图（有后继镜头写硬切，最终镜写结束）。缺任一项应补回，不允许省略。固定机位可写“焦点稳定在具体主体”，不强制转焦；稳定焦点不是遗漏焦点字段。

用起始、变化和结束状态检查同一主体/空间锚点与连续性，输出仍为上述单行五要素。静默、等待和固定观察允许前后构图、姿态或焦点相同，不能强行制造变化。运镜字段内不放秒数、时间码、百分比、固定时间点，不写“接上个、同前、保持不变、继续推进”等抽象依赖语。镜头时长只放镜头标题。单镜时长推荐一般不低于 2.0 秒（除特殊爆点快剪外）。细节粒度和路径范例见 [描述细节与运镜设计](description-and-camera.md)。

## 屏幕文字处理

区分“字幕、水印等非剧情叠字”和“道具或剧情系统界面承载的文字”：前者不添加，后者允许按剧情需要出现。系统控制面板即使悬浮、作为主角主观界面或以整屏界面呈现，也不按字幕删除。剧本明确要求字幕仍不恢复对白字幕。

- **叠加文字**：删除对白字幕、水印、片名、章节标题、人物介绍条、时间地点字卡、弹幕、台词气泡等非剧情叠字要求。原对白、OS和旁白按原文保留，仅发声，不同步上屏；不自动安排后期补字幕或字卡，不以乱码或符文替代。
- **道具上的文字**：信件、圣旨、招牌、碑刻、书页及实体手机/电脑屏幕等可以呈现剧情需要的文字。写明文字属于哪个物件、哪个表面、位于何处及书写形式；随载体保持透视、遮挡和运动，不漂浮于画面，不把对白伪装成道具字幕。不是每个道具都必须添字，原文没有文字用途时不为装饰新增。
- **剧情系统面板**：原文或已确认设定明确主角获得系统、打开控制面板、查看任务/属性/背包/商店等界面时，可以显示必要的标题、任务短句、属性名、数值、奖励及按钮文字。不能因悬浮或整屏显示而删除，也不强制改成实体屏幕或只用声音。普通剧情不能为显示说明文字擅自增加系统面板。
- **界面外观与状态**：固定面板形状、边框、色彩、透明度、栏目位置、字色及按钮样式，每个独立段首次出现时写全适用的详细描述；文字归属具体栏目或按钮，不散落成额外字幕。明确已知的显示方式、位置、打开/关闭状态及观看者；主角专属界面不让其他人物无依据看见或回应。主观整屏界面不强套实体表面透视。属性值、任务进度、积分、奖励和选中项按原剧情事件更新，后段继承；固定布局不等于把动态数值永远锁死，不补造未知数值或奖惩规则。
- **长文简化**：先识别原文的目的与关键事实，将道具或系统界面实际需要看见的内容压缩为几个简单文字或一个短句，不机械规定字数。例如一封长信只为索要钱财，可在信纸上仅写“要钱”。内部保留“原文内容 → 简化文字 → 适用道具与段落”的映射；最终视觉提示词只指定定稿短文，不要求同时显示全文或填充其余小字。
- **准确性与剧情保真**：简化不能改变请求、命令、否定、对象及结果；金额、期限、姓名、罪名或原文用字若承担证据、反转或后续行动因果，须保留相应关键内容，不能一概缩成“要钱”“赐婚”等词。确实依赖完整原句时保留必要原句，不为短而改义。道具文字简化仅改变物件上的视觉表达，不缩写、替换原对白，也不擅自改动人物认知。
- **跨段一致**：同一道具的定稿文字、字色、位置、排布及书写形式随固定外观描述复用；无剧情依据不换词、不增字、不改布局。背面、封口未开或被遮住时不要求显示内部文字。详见[道具外观与跨段一致性](description-and-camera.md#道具外观与跨段一致性)。
- **必要信息承接**：被删除的叠加文字若含理解剧情不可缺少的信息，优先由原有场景、动作、台词或已有旁白承接；确无承接时，可将原文必要内容转为旁白或有依据的系统声，不新增事实或擅自让角色说话，并重新核算时长。道具和剧情系统面板文字允许出现，不为避字而强制把信件、圣旨背向镜头，隐藏系统界面，或一律转为朗读。
- **成品边界**：段落标题、场景名、镜号和字段是制作文本，不是视频画面内容。原台词中提及“字幕”“水印”不等于显字指令；不误删原对白，不新增固定显字字段，也不在每镜重复“无字幕、无水印”。

复核全部生成字段及参考素材用途，按文字的真实承载位置判断：如“右下角浮现剧名”应删除，“信纸中央写着‘要钱’”及原文已有系统的“任务栏显示‘寻找钥匙’”可保留。检查道具短文是否准确、图文位置是否成立、跨段是否一致；关键词命中仅供定位，结构校验不证明实际成片的道具外观或文字一致。

## 输出前语义质检

| 检查 | 通过条件 |
| --- | --- |
| 原文覆盖 | 每段原句、动作、台词和信息揭示都有镜头对应，无概括、删词、漏段或擅自续写；叠加显字指令移除，道具文字允许按原意简化，必要信息有画面或声音承接 |
| 屏幕文字 | 无字幕、水印、悬浮标题/字卡等叠加文字；允许的文字属于具体道具或剧情系统面板，不以悬浮/整屏为由误删剧情界面；长文简化准确且未删关键事实，定稿短文与排布跨段一致；原台词保留且不自动配字幕，无逐镜禁字口号 |
| 节拍 | 按意图与情绪转折，段内有推进、落点和必要反应；不是凑秒 |
| 时间 | 台词听得清、动作做得完；每段（含尾段）10.0–15.0秒；所有标题等于实际镜头之和；单镜时长推荐一般 $\ge 2.0$ 秒（极速动作除外） |
| 场景 | 段首只有起始场景；切换在对应新镜之前；地点、时间、内外完整 |
| 场景布局 | 每个独立段与段内新场均有必要空间关系，无“同前”等依赖；只写环境，不含人物或画外存在说明；不为凑字段编造区域或增加空镜 |
| 空间与参考依据 | 固定地标跨镜/跨段相容，环境状态有触发并继承；世界方向与画面方向分清，通道、遮挡及机位可成立；已确认图与文字相容，未显示区域不冒充已核验 |
| 构图一致性 | 标题标签对应实际主体落点、背景和裁切，关键动作可见，运镜终点与画面及接切相容；不逐镜复制全室布局 |
| 光源连续与换场 | 光源世界位置和状态相容，反打屏幕光向按机位转换；真实光变有依据，段内换场有独立本场光影，人物表现不混入环境字段 |
| 场景命名 | 以可复用完整空间命名，必要层级从大到小用半角短横线 `-` 连接，不强制三层；场景字段、资产引用及图片清单同名，局部细分旧名已映射合并，来源原句与台词保留原写法 |
| 场景合并与复用 | 一个视频优先在一个真实场景内完成；卧榻前、窗边、门口等局部未各自建档或重复配图，换景别/机位/普通照明未增加场景资产；确需拆分有独立空间或实质环境依据，未合并不相容地点或改写剧情，环境地标与人物走位连续 |
| 人物 | `出场人物`只含实际发声、关键动作或关键反应者，角色身份具体，无被提及者混入；它不等于场景在场人物 |
| 案例读取边界 | 常规创作未把examples/成品当作默认上下文；格式结构固定，剧情、机位、镜数和动作按当前任务设计 |
| 群像取景（触发时） | 已按占位核对画框与遮挡，未入画有空间原因；运镜全过程和重新展示区域时的人物数量与最近状态相容，参考预算覆盖整段可见需求 |
| 群像层级 | 同一连续场景已区分场景在场、本段入画、本段出场和画外在场；出场人物少不等于场景里只有这些人 |
| 群像入退场 | 实际入退场有剧情依据与状态衔接；仅因取景或遮挡不再可见者已在内部记录核对，不强制在成品逐人说明画外状态 |
| 整桌/全景可见 | 画面人数与实际取景覆盖的占位区域及场景在场名册相容；可见空座有依据，真正未覆盖者只需内部核对，不为解释其存在新增声音、道具或离场 |
| 角色造型命名 | 需要区分的角色造型、年龄阶段或实质状态统一写为“角色名-限定词”，视觉字段与图片清单命名一致，声音字段按稳定发声身份映射 |
| 小说造型对照 | 已提供小说时按事件定位对应章节，记录相关角色衣着、妆发和状态的出处及适用范围；小说未提供或未交代的部分明确为缺口或拟定，不编造证据 |
| 造型分期与继承 | 剧本决定剧情，小说补足相容造型；多套衣着已区分、同套已复用，换装和伤污恢复有依据，没有提前采用后期服饰或按换集强行换衣 |
| 视觉与发声映射 | 当前造型名用于出场人物、画面、运镜和图片清单；声音锚点使用稳定发声身份名，必要时注明当前造型，换衣不换音色身份 |
| 参考图预算 | 每个独立生成视频按全段实际图片需求的并集合计最多9张；角色/群演、场景与其他图片共用预算，同图复用不重计，多场景、多造型或额外视角按实际张数扣减；未制作但必需的图片已计入计划名额 |
| 预算与景别联动 | 已用符合既有占位的景别、角度和裁切控制非必要人物入画；未把逐镜轮换、背景虚化、背影、删姓名或多人拼贴当作省图；未删关键动作/反应，群演类别已落实实际参考需求 |
| 超额处理与衔接 | 取景调整后仍超9张者已重组相邻节拍或拆成独立视频，每段10.0–15.0秒且预算分别合规；起止动作、位置、朝向、造型、持物及换场到达连续，未凭切镜增减或瞬移人物 |
| 系统面板（剧情存在时） | 详细界面外观与固定栏目跨段复用，观看权限及打开/关闭状态有依据；属性、进度、积分、奖励等随原事件更新并承接，未杜撰数值或系统机制，未把动态内容锁死或擅自添加剧情系统 |
| 状态/道具 | 坐站蹲躺、位置、朝向、持物逐镜延续；改变有动作；跨段写全 |
| 道具外观与独立段 | 同一道具名称、材质、颜色、形制、尺寸比例、结构、识别特征及文字相容；每个独立段首次可见时已在画面写全适用的详细外观，不只写名称或同前，不套用服装解耦；开合、破损、持有与位置状态有依据并延续，取景未显示的部位不强写为可见 |
| 对话与轴线 | 谁对谁说明确；严格遵守 180° 轴线；画左角色视线投向画右、画右角色视线投向画左，对视锁定防撞车 |
| 角色音色 | 每个实际发声身份有唯一 V-ID；同角色没有多 ID，同 ID 没有多角色；基础描述跨镜一致 |
| 音色锚点 | 每个含对白镜头都带锚点，紧跟在发声身份标准名后；锚点含3–5项稳定特征，不混入临时情绪或受伤状态 |
| 音色绑定 | 角色音色卡、分镜锚点、参考音频/Voice ID/种子信息一致；缺失素材写“待配置”，不把文字锚点冒充声学锁定 |
| 嘴型 | 无台词明确标注；无口部动作时闭口；OS/旁白/听者不做他人说话口型；原文自然口部动作及非语言发声完整保留 |
| 画面与景别 | 人体截取符合解剖基准（胸/腰/膝/锁骨）；机高与倾角解耦；关键动作有触发、接触和结果；动接动出入点连贯 |
| 对白观看对象 | 每个对白节点已判断受影响者及最有信息的反应；听者承担这一拍时优先呈现其反应，不把当前发言者当成默认画面主体；换人说话不自动切镜，反应完成也不自动切回说话者，无机械一人一句正反打 |
| 反应依据与声画分配 | 反应有具体台词/动作触发且符合当前认知，不提前反应、不编造情绪或立场；画外发声者、对象、台词片段和音色身份清楚，听者不做他人口型；原台词时序、朗读时长、轴线及硬切规则保持一致，不靠反应镜凑数 |
| 景别节奏 | 整体略快，景别随信息、动作与情绪节点调整；空间交代完成后及时转向表演或细节，没有长时间沿用失去表达作用的同一景别；连续相同景别或长镜有持续叙事价值，不靠固定间隔、镜数配额、机械推近或无意义碎镜制造变化 |
| 长镜与低镜数复核 | 超过4.0秒的普通镜头、10.0–15.0秒却仅1–2镜的段落已逐一复核；超过6.0秒且承载多节点的固定对白镜原则上已拆开，保留者内部有具体可见递进与不可切断依据，未用“台词完整”或微小目光变化搪塞 |
| 摄影机运动克制 | 景别变化主要通过硬切到稳定机位完成；必要连续跟随或空间揭示才运动，无连续推拉/变焦代替剪辑；相邻推拉、段内推拉过半或反复摇移均已复核，未以另一类运动绕过切镜 |
| 景别变化一致性 | 标题与运镜说明的起始景别、画面可见范围及结束裁切相容；单镜景别变化有明确相对运动，真实切镜另有镜号；对白跨镜的画内/画外来源、台词分配与时长连续，不重复计时或错配嘴型 |
| 构图留白 | 视线前方有 Look Room；移动主体前方有 Lead Room；人像头顶有适当 Headroom；避免主体贴边撞框 |
| 运镜规范 | 一句话含起位、观察/跟随、运动、焦点、结束五要素；运动路径使用推/拉/摇/移/升/降/环绕/固定/复合九类动词起头；区分物理推与变焦；默认固定，必要运动才按需写速度曲线；摄影机起位距离使用公制单位（米/厘米），不用“步”计量；无时间码；切镜以新镜号表达 |
| 人物站位与动作步数 | 固定站位有清楚的参照与相对方位，必要时用公制近似距离，不强制数字化；“迈近一步、后退半步”等动作步数可保留，不机械换算或仅因含“步”判错；接触、避让与遮挡相关动作的方向和落点明确 |
| 光影与景深 | 自然低饱和、有来源光线、背景可辨；景深层次可控（全景深/环境浅景深/极浅景深）；字段不含人物 |
| 环境微动取舍 | 已结合可见元素、物理条件与叙事重心决定是否描写，静稳镜头允许不加；无装饰性新增天气、道具或事件，无逐镜数量指标或微动凑时长 |
| 环境微动执行（选用时） | 对象、来源、必要方向与幅度明确，速度合理；变化在当前景别可读、强度不抢主体，固定结构稳定，无机械同频摆动或无依据曝光波动；运动写“画面”，声音和真实光变各归对应字段 |
| 环境微动连续（选用时） | 同场风向、强度、烟汽来源和火焰状态相容，改变有依据；事件反馈有触发与衰减，仅在动作接切或剧情需要时衔接具体运动阶段，不强锁自然摆动相位 |
| 可执行性 | 主体清楚，动作落点可见，遮挡可解释；地标、轴线、距离、取景比例和尺度相容；长镜节拍有先后且做得完，无多人独立复杂动作同时堆叠 |
| 特殊打斗启用 | 仅原文或用户要求支持的持续近身交锋启用；普通冲突不扩编连招，结束后退出；画风与风格化效果另有依据 |
| 特殊打斗动作（仅启用时） | 攻击、格挡/命中、重心变化、恢复支撑与后续动作接续；能力、伤势、胜负、道具与环境损坏持续，时间容纳实际动作 |
| 参考方法迁移（学习/新例任务时） | 从当前目标、身体限制和空间重新设计攻防及观看重心；不能只换角色名、地点与参数后复用参考的动作/镜头顺序；忠实改编任务仍保留原事件 |
| 特殊打斗摄影（仅启用时） | 关键接触可见，必要肢体在画内；跟移/环绕/穿越路径可通行，轴线过渡明确，插入剪切另有镜号；不以特效和单人反应替代全部交锋 |
| 声音层级 | 环境、关键事件与细节声有轻重和距离；声画同步；声音跨镜连续且不重复分配整句；无依据不添音乐、对白或非语言发声 |
| 声音槽位 | 需要分层时，环境底层、关键事件声、动作拟音、对白、非语言、静音/BGM和声音桥接的取舍有依据，不为填满槽位堆声 |
| 景别 Profile | 已明确采用对话表演型、空间叙事型或动作奇观型；景别重心与项目任务一致，没有把固定比例当硬规则 |
| 参考素材 | 使用普通清单和标准资产名；不默认出现 `@[...]`、首帧锚定或未确认的素材用途 |
| 起始/结束状态 | 用文字记录人物姿态、位置、朝向、视线、手部/道具和空间地标；不依赖首帧锚定，不用“同前”代替状态 |
| 复杂度 | 已检查画中画、多人独立复杂动作、多次硬切、跨时空和参考过多；高风险镜头已拆分、降动作或明确风险 |
| 转场 | 所有镜间画面只用硬切，有后继镜头的镜尾明确硬切；无叠化、淡入淡出、溶解、闪白、黑场过渡、遮罩/遮挡、甩镜或画框穿越等转场特效；动作匹配与自然声音跨镜不改变硬切方式 |
| 负面约束 | 段级优先保留5–8条真正影响结果的限制；不逐镜重复同一组“不要”，不无依据增加平台或风格禁令 |
| 长文续作 | 本批范围覆盖完整、镜号连续、接续状态可恢复，新段自身信息完整 |
| 输出边界 | 默认只有段落版、固定字段、独立@，完整分镜正文放同一个代码块；不含母版、分析和额外镜间说明 |
| 画外人物与内部备注 | “画面”“运镜”及光影字段只含实际可见内容；本镜未入画人物的姓名、站位、姿态、动作及“在画外/未入镜/仍在旁边”等说明已全部删除，不能以视线或对话对象为由保留。可见主体只写目光方向与反应，必要画外发声及身份仅在“台词/声音”中说明；人物存在和连续性只留内部，不误删身体局部、影子/倒影、背景人影及运镜中实际显露的内容 |

## 自动检查

在技能目录运行：

```text
python scripts/validate_storyboard.py 分镜文件.md
python scripts/validate_storyboard.py 分镜文件.md --start-shot 31 --start-paragraph 8
python scripts/validate_storyboard.py 分镜文件.md --check-voices
python scripts/validate_storyboard.py 分镜文件.md --check-scenes --check-editing --check-voices
```

普通结构检查兼容旧稿及新字段，不自动补写历史分镜；新版交付必须加 `--check-scenes`，严格要求每段起始场景及段内换场的布局、段内本场光影，并检查非空、顺序、重复、作用域和明确外部依赖。结构通过不证明空间正确；地标、光源、机位、参考相容性与画外人物清理须人工复核。

脚本只检查可确定的结构和数值：段与镜的连续编号、正时长、精确求和、所有段落的10.0–15.0秒范围、标题/字段、运镜中的摄影机/焦点/结束及运动词、段间分隔符、部分抽象依赖语及非法时间表达。使用 `--check-controls` 时，还会检查可选制作控制卡中的景别 Profile、参考素材禁用项、首帧锚定、群像人物层级、整桌人数相容性和9张参考图预算。使用 `--check-voices` 时，会检查含对白镜头是否有音色锚点、锚点是否为3–5项稳定描述、V-ID/角色/基础描述是否跨镜冲突，以及音色卡与锚点是否一致。使用 `--check-editing` 时，对明确的转场特效指令与缺失硬切标记报错，对超过4.0秒、低镜数、重复取景及推拉密集列出 REVIEW 待复核项（不自动判定不合格）；必须人工修正或在内部记录保留依据。它不校验三帧差异、实际声音相似度或模型是否遵循提示词，也不能验证五要素的实际完整性、原文覆盖、细节质量或路径能否执行。按上表做语义检查后才能交付。

小说情节匹配、服装证据、造型分期与视觉/发声身份映射均需人工语义复核，不能以脚本通过代替。

道具及剧情系统面板的外观、文字简化与跨独立段复用须人工语义复核，现有脚本不检查这些内容，不保证模型实际生成一致。
