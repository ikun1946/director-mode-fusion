# 导演调度与表演

## 剧情与人物建立（原文第1–12节）

- 先确定场戏目标：立人物、立关系、压迫、打脸、反转、暧昧、爆点或钩子。视觉中心不一定是说话最多的人；听者反应可以承载关键台词。
- 新场景优先考虑宏观→中观→微观，用物件、声音或视线引出人物；这是空间组织方法，不要求每次增加三个空镜。现代都市可从街道到车窗再到车内动作；宅院可从门廊到桌上账册；边关可从雪原到院门脚印。建立镜头应短且有效。
- 主要角色首次出现，以姿态、眼神、动作习惯、身份关系和情绪底色设计专属人设镜头。组织入场、当前状态、主体动作、有效反应及与事件/人物的联系，不机械拍走路全过程。
- 女性角色通过身姿、仪态、肩颈线、行走姿态、低头角度、手指和情绪控制表现人物价值，避免无意义身体凝视。
- 反派不用“冷笑/阴沉”包办：可用降低音量、空间逼近、构图压力、局部遮挡、敲杯沿、整理袖口、摩挲戒指或凝视表达威胁。选择与原文动机相符的少量动作。
- 动作因果：起势意图→关键过程→落点→物理反馈→角色反应。可省掉观众能脑补的机械过程，不省决定因果的动作或结果。
- 每镜至少服务叙事、人物、情绪、关系、笑点/爽点、视觉看点中的两项。补场景/角色建立、起势与落点、必要听者反应、爆点和钩子；删重复表情、重复吃惊、无意义环境与走路。

## 台词与时长（第10–11、19、31节）

一句完整台词默认一个镜头，不按逗号机械拆。超过约6秒时检查是否出现信息、关系或情绪转折，再决定正反打、同框调度、焦点转换或听者反应；不因时间变长就强制切镜或转焦。持续表演、等待或连续调度仍有效时可以保留长镜。需要拆镜/分段时在真实语义或动作落点拆开，保持台词文本、顺序和发声者连续，可明确分配画内/画外发声，并遵守每段10.0–15.0秒。

| 台词汉字数 | 参考时长 | 调度 |
| --- | --- | --- |
| 1–6 | 1.5–2.0秒 | 短句落点清楚 |
| 7–12 | 2.5–3.5秒 | 保留语气 |
| 13–20 | 4.0–5.5秒 | 轻微内部调度 |
| 21–32 | 6.0–8.0秒 | 对象反应或焦点变化 |
| 33–45 | 合计8.0–11.0秒 | 通常拆2镜 |
| 45以上 | 按实际语义和朗读 | 通常2–3镜；仍过长则继续拆，不挤压语速 |

这些是估时起点，不是压缩台词的公式。情绪、停顿、外语、语气词及动作耗时均需实际判断。小范围转头、视线、握物可与对白并行；需先后完成的动作要另计时间。长对白避免叠加多人走位、复杂手部动作和复杂运镜。

| 无台词内容 | 参考时长 |
| --- | --- |
| 普通动作 | 0.3–0.6秒 |
| 普通反应 | 0.3–0.5秒 |
| 关键反应 | 0.6–0.9秒 |
| 关键动作 | 0.8–1.2秒 |
| 爆点动作 | 1.2–1.8秒 |
| 必要空景/纯环境 | 0.3–0.6秒 |
| 新场景建立 | 快速完成，通常0.8–1.2秒以内 |

不能要求复杂起身、开门、搬箱、奔跑等动作在0.3秒完成。先拆清关键动作，再按实际可读时间分配。段落10.0–15.0秒是范围规则，上表是建议；不能反过来牺牲剧情和物理可行性。**单镜时长推荐一般不低于 2.0 秒（除特定爆点、极速打斗或快剪闪回外）**，避免产生 AI 难以执行的超短碎镜（<1.5s），贴合主流 AI 视频工具单条生成规律与下游剪辑拼接。

## 状态与人物筛选（第18、20、23–24节）

连续性工作记录可用：角色｜所在场景｜姿态与位置｜身体朝向｜视线｜左手｜右手｜道具位置｜本镜变化。这是工作记录，不加入最终固定字段。

- 上镜坐着、没有起身动作，下镜仍写清坐在何处；站着、蹲着、躺着、倚靠、行走同理。
- 道具转移写出交接或放置动作。人物离开画面不意味着道具消失；重新入画与记录一致。
- 跨段首镜重新交代必要人物、环境和当前状态。允许“仍坐在书桌右侧，右手压住文件”这样自足表达；不允许“保持原姿势”“同前”“接上一段”。
- 名单只列本段实际说话、关键动作或关键反应的人。仅被提及、无剧情作用的背景人不列；群体只有集体发声或主体动作实际影响剧情才用“府兵”“围观百姓”等功能名称。
- 已有姓名就写姓名，避免用“三人、几人、大家、众人”代替角色识别。听者只有明确关键反应才计入；仅作为背景听见不自动列入。
- 画外/电话角色有实际台词时在出场人物中标明“姓名（画外/电话声）”，不凭声音虚构其入画；纯叙述旁白单列声音来源，不当成画面角色。

## 群像场景与在场连续性（实现层补充）

群像或固定占位场景（饭桌、会议桌、炕桌、围坐、车厢、队列等）必须把人物分成三层：

| 层级 | 含义 | 用途 |
| --- | --- | --- |
| 场景在场人物 | 这个空间里实际有谁 | 保证同一场景跨段不凭空增减人 |
| 本段入画人物 | 当前画面能看见谁 | 决定构图、遮挡和可见范围 |
| 本段出场人物 | 本段实际说话、关键动作或关键反应的人 | 写入最终 `出场人物` 字段 |

- 同一连续场景跨段时，必须保留场景人物名册；出场人物少，不代表场景里只有这些人。
- 记录座位或站位、固定地标、桌面/地面道具、门窗方向、主光方向和本段可见范围（整桌/局部/其他）。
- 新角色进入已建立空间，必须有入口、揭示或画外声音；不能直接出现在原座位而不交代。
- 旧角色离开画面，必须有离场动作、画外声音/台词、连续性锚点，或明确切到局部取景并说明其仍在画外。
- 整桌或全景可见时，画面人数必须与场景在场名册相容；空座必须有原因，不能无交代地让旧角色消失。
- 相邻段落用结束状态和起始状态交接；允许用门口声、椅子移动、脚步、画外呼唤、视线或新角色入画半步做桥接。
- 群体只有集体发声或主体动作实际影响剧情时，才用“府兵”“围观百姓”等功能名称；普通背景人群不列入出场人物。

### 参考图预算

每个视频或分镜段落最多使用9张参考图：

- 1张场景图；
- 最多8张角色图；
- 同一角色的不同造型/状态按图片张数计算；
- 道具、色卡、故事板等其他参考也占用9张总预算；
- 超过8个需要独立角色参考的人物时，拆段、降为无独立参考的功能群像，或改为画外声。

## 对话与口型（第10、16–17、34节）

| 情况 | 写法 |
| --- | --- |
| 面对面对话 | 沉砚看着温知予说：“你先坐下。”画面同步写沉砚的坐姿、视线与身体朝向。 |
| 身体侧对 | 温知予仍站在门边，身体侧对沉砚，回头看向他；温知予对沉砚说：“我马上回来。” |
| 隔门 | 谢无恙隔着门板对门外的姜云禾说：“别出去。” |
| 电话 | 温知予通过手机对电话另一端的沉砚说：“我到了。” |
| 听者镜头/画外对白 | 沉砚在画外对温知予说：“你先坐下。”温知予闭口，不做说话口型。 |
| OS | 温知予OS：“原文内心独白。”画面人物闭口，不做说话口型。 |
| 旁白 | 旁白（画外音）：“原文旁白。”画面人物闭口，不做说话口型。 |
| 无对白 | 无台词；门轴轻响。温知予闭口。 |

OS/旁白不是面对面对话，不强配听者。原文未设发声者的旁白标“旁白”，不捏造角色。普通台词不能只有“姓名：台词”。多人轮流说话要明确顺序；避免多人同时开口。只开口没有表演支点的对白必须重写画面。

### 180° 轴线守则与屏幕视线朝向锁定（Screen Direction）

为彻底解决 AI 视频生成正反打对视时频繁发生的“视线撞车”（两人均看同一侧、眼神错位），对白镜头必须遵守轴线与屏幕视线规则：
- **建立关系轴**：场景建立双人关系时，确立两主体之间的虚拟直线（动作轴/关系轴）。机位在整组对话中必须锁定在轴线的同一侧（默认机位侧），严禁无过渡跳轴。
- **画内屏幕朝向锁定（Screen Direction）**：
  - 画左角色（置于画面左侧三分线）：**视线必须明确标注“视线投向画右（对视）”**；
  - 画右角色（置于画面右侧三分线）：**视线必须明确标注“视线投向画左（对视）”**；
  - 单人近景或特写反打时，必须延续上述各自的屏幕相对视线方向，确保观众在剪辑组接时获得连贯的对视心理认知。
- **合法越轴**：仅允许通过中性镜头（正对角色脸部或背影过肩中间过渡）、连续运镜平滑滑过轴线、或角色走位打破并重建新轴线。

### 剪辑动接动（Cut on Action）与动作接点规范

为避免剪辑组接时的动作重复跳帧或凭空瞬移，跨镜头动作需明确出入点物理接续：
- **切出帧时机（Out-point）**：写明前一个镜头的动作完成至哪个瞬间切出（例如：“递出信封、对方指尖刚刚触碰到信封边缘瞬间，切出”）。
- **切入帧接续（In-point）**：写明新镜头承接该物理瞬间的初始状态（例如：“从信封接触一瞬间切入，温知予手指正握住信封下沿，顺势收回”）。

## 运镜配合台词

镜头标题保持“景别/视角/构图”三个纯标签；机位位置、公制距离和运动写在运镜字段。具体路径、遮挡揭示和尺度检查见 [描述细节与运镜设计](description-and-camera.md)。

对白镜头可以通过说话者的表演、听者的态度变化、双人距离变化或有依据的物件动作推进。摄影机只在这些变化需要重新组织可见信息时移动；眼神到嘴唇再回眼神不是固定流程。

稳定观察示例（单镜字段示意，不是完整段落）：

> 运镜：摄影机在沈砚右肩后约0.8米·平视·中近景，看温知予面部，固定机位（带微幅呼吸感）；焦点稳定在温知予眼睛；结束于温知予视线收回后的三分构图，静止停留。

对白跨镜时允许声音先进入、画面后揭示发声者，或保留同一声笑/一句话连续切换空间；确保声音来源、对象与实际台词分配清楚，不重复播放整句。

## 可见情绪与适龄动作（第32–36节）

从眼神、眉眼、嘴角/下颌、呼吸、手部、肩颈和身体重心中选出能准确表现这一拍的变化；不逐镜堆齐所有部位。

| 情绪 | 可选择的可见变化 |
| --- | --- |
| 愤怒/克制 | 眉心压紧、视线钉住对象、嘴角绷直、指尖收紧、肩背变硬 |
| 委屈 | 睫毛轻颤、抿嘴、鼻尖微皱、抓紧衣角、想抬头又垂下 |
| 震惊 | 视线骤停、眉峰抬起、呼吸卡住、手停在半空、从结果看回人物 |
| 害怕 | 先看出口、肩膀微缩、吞咽、脚尖试探后撤、手护在胸前 |
| 开心 | 眼睛亮起、眉尾放松、嘴角翘起、身体前倾、伸手靠近目标 |

无台词、OS和旁白镜头无口部动作时保持闭口，不做说话口型；通常用唇线、眉峰、视线和呼吸表达反应。原文明确要求哭笑、喘息、进食或干呕等自然口部动作时保留对应动作与非语言发声，并说明不是对白；不能为模仿参考擅自增加这些动作。

萌娃有原文依据时才使用适龄动作：偷瞄后移开、歪头、缩脖探头、认真点头、抠手指、抓衣角、抱紧物件、握拳又松开、双手比划、踮脚、小步后退、贴近可信任的人、抿嘴或忍笑。成人角色不套萌娃动作，不因参考作品加入原文没有的儿童。

对白推荐：短句用中近景加一次表演变化；长句切听者或变焦点；冲突先双人中景建立关系再互切；萌娃认真解释可接成人短反应再回萌娃补充。

有效反应区分没听懂、怀疑、认知变化、强装镇定、忍笑、心疼、警惕。一个反应抓一个落点，完成后回说话人或进入动作/结果，不能堆三四个同义反应。萌爽节拍可参考“正常铺垫→萌娃认真→成人停顿→萌娃继续→关键动作/结果→反应补刀”，仅在符合原文时采用。

### 快节奏剪辑与高张力镜头语言（Pacing, Impact & Micro-acting）

不搞机械生硬的套路模板，而是将快节奏动作、强冲突与反差戏份中的**视听剪辑动能、机位物理张力与人物微表情**提炼为通用的导演镜头语言。根据实际剧情灵活选用、有机组合：

#### 1. 截断式剪辑与听觉推背感（Interrupted Cutting）
- **音画强截断**：台词或动作不必完整演完再切镜。在人物情绪或动作推向高潮的半截，被突如其来的画外暴响、暴力动作（如踹门、重物摔落、枪响、掌掴、兵刃出鞘）硬生生切断（如“我的——”尾字截断接撞击声），形成强烈的听觉冲击与剧情突变推背感。
- **声响先行与余响留白**：爆点声效（重踏地面、木门撞墙、杯盏粉碎）直接作为入画推进动力；前一长句声色俱厉输出后，切入新镜头时用“室内死寂、残余空气回响”与人物的沉默形成强烈的反差留白。

#### 2. 动静与视角的极端反差组接（Extreme Contrast in Motion & Perspective）
- **动静急刹对撞**：极度动态的冲击动作（如抓狂抱头晃脑、暴烈破门、疾步跨入）紧接完全凝固的静止反应（倒吸冷气、手滑跌落、目瞪口呆），通过大幅度运动到骤停的急刹，营造极强的心理停滞感与戏剧反差。
- **极端视点造势**：平视常规机位与贴地大仰视角（距地 0.2–0.3m 贴地仰摄）形成强烈落差。利用大仰角贴地构图赋予闯入者或压迫者天然的居高临下威压，不需要靠台词说明“有威压”，构图本身即是压迫。

#### 3. 人物生理机制与情绪“瞬间换挡”微表情（Physiological Reactions & Emotional Shift）
- **写实生理机制代替概括词**：彻底禁止泛写“震惊、害怕”。细化到“双眼睁大瞳孔骤缩、倒吸一口冷气、身体失控一颤、抱头双手滑落跌在腿上、唇线合拢”等肌肉受惊与神经本能反应，让表演具备真实可信的生理依据。
- **情绪的瞬间换挡（预期违背）**：在强刺激或离谱宣告后，打破人物陷入常规恐惧或抱头痛哭的平庸套路；通过眨眼、微蹙眉心、嘴角抽动等微妙神经反应，在极短瞬间从“惊魂未定”光速换挡为“看疯子、极度荒谬、怀疑人生、你没事吧”的冷幽默反差，用高级的反套路微表情强化角色内核。

#### 4. 镜头运动质感与物理呼吸（Camera Texture & Easing）
- **快推急停（Snap Push）**：在主体受惊、动作爆发或重要线索暴露瞬间快速推近，在信息点或惊愕瞬间骤停收紧，放大视觉中心。
- **定点仰摇与手持呼吸感（Tilt with Vibration & Handheld Breathing）**：贴地机位承接暴力撞击瞬间顺势微仰，并带有碰撞震颤的手持微幅呼吸感，模拟真实手持机位受冲击波及的临场感，彻底消除 AI 视频纯三维渲染的死板与机器感。

#### 5. 单人高频正反打的干净隔离（Spatial Clarity）
- 强冲突不强求双人同框。严格执行 180° 轴线与画内屏幕视线朝向（画左主体视线必须投向画右，画右主体视线必须投向画左）。将对抗拆解为纯粹的单人高频正反打，既保障 AI 视频生成零融人、零肢体粘连与零双胞胎，又让剪辑节奏利落干净、剑拔弩张。
