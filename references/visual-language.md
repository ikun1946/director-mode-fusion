# 光影、构图与剪辑融合

## 应用范围

原文第28–29节规定《逐玉》视觉底色，第32节补充《糯糯下山，师兄们都慌了》镜头组织。以下是用户PDF所定义的参考方法，不声称做过原剧逐帧研究，不复制作品剧情、角色关系或具体镜头。

保留项目已定动画/真人/二维/三维画风。古风使用对应自然环境色；现代场景依现实材质和光源迁移原则，不强加灯笼、古装或木屋。剧情准确、连续性、完整对白与时长优先。

## 光影与成像

- 低饱和自然色：米黄、土褐、灰绿、旧木色、蓝灰、冷白。避免高饱和糖果色、强青橙对撞。
- 中等对比、柔和高光、黑位不压死；暗部保留木纹、织物、石墙、烟尘层次。
- 光源有来源：日光、窗棂侧光、烛火、灯笼、火盆、雪地反射光，或符合时代的实际灯具。避免无来源面光/顶光和影棚塑料感。
- 景深与背景分离度（Depth of Field）：
  - 全景深（Deep Focus）：前后景皆清晰可辨，用于环境叙事、群像对峙与空间交代。
  - 环境保留浅景深（Medium Shallow Focus）：主体边缘锐利，背景门窗家具轻度柔化但轮廓结构依然可读，绝不糊成纯色块。
  - 极浅景深（Ultra Shallow / Macro Focus）：仅用于极端物件特写或主观情绪剥离。

| 场景类型 | 环境配色与光源 | 效果 |
| --- | --- | --- |
| 乡野、街巷、日常 | 米黄/土褐/灰绿/旧木，柔和日光，亮部微暖，空气清透 | 生活感与自然关系 |
| 家庭室内 | 暖灰/棕褐/亚麻，门窗侧光，暗部和木织纹理可辨 | 朴素、安静、真实 |
| 雪景、夜景 | 蓝灰/冷白/浅青灰，局部灯火暖色；雪保冷白 | 清冷环境中的局部温度 |
| 战场、权谋 | 铅灰/暗青/褐黑，适度提高反差，硬质金属石材与烟尘 | 压迫、危险、秩序 |

不把所有场景统一套冷滤镜，不把雪变蓝紫。原文的饱和度降低约10%–20%、高光压低约15%–25%只是参考，不是必须填写的参数，也不是平台API参数。

人物面部可比环境亮约半档，肤色自然微暖、五官和纹理清楚；这是内部成像参考。必须写出时放“画面”，**绝不写进光影字段**。发丝、服装及人物皮肤纹理同样放“画面”。

正确光影字段示例：

> 本段统一光影/质感：窗侧自然暖光，低饱和暖灰与棕褐色调，高光柔和，暗部木纹与背景织物细节清楚，环境保留浅景深使门廊结构清晰可辨，沿用项目既定成像风格。

## 景别与机位视角

### 1. 人像景别解剖裁切基准（Anatomical Cutoffs）

为避免 AI 视频生成中人物比例漂移与尺度忽大忽小，景别以人体标准截取点为物理锚点：

| 景别 | 代码 | 画面下沿人体裁切基准 | 叙事与表演核心功能 |
| --- | --- | --- | --- |
| 大远景 | EWS | 人物呈点状剪影（占画高 < 1/10） | 天地尺度、极端环境、孤独与宏大叙事 |
| 全景 | FS | **脚底触底，头顶微留白**（全身完整入画） | 肢体走位动线、完整服装造形、环境站位关系 |
| 中全景（牛仔） | MFS | **大腿中部**（膝盖上方约10–15cm） | 拔枪/拔剑、手部下垂持物与下半身发力起势 |
| 中景 | MS | **腰部 / 皮带扣** 附近 | 双人关系、桌面动作、主要行动线推进 |
| 中近景 | MCU | **胸口 / 胸腺**（横穿胸前） | **对话表演主力**，面部神态与手部起势兼顾 |
| 近景 | CU | **锁骨 / 肩部上方**（仅露肩线） | 眼神、微妙嘴角抽动、心理微表情与情感张力 |
| 特写（紧凑） | BCU | **下巴下沿至额头发际线**（头顶可微切出画） | 极度情绪冲击、秘密揭晓、窒息压迫感 |
| 大特写 | ECU | **局部解剖器官或物件细节**（仅单眼、指尖碰触、唇线） | 触发点、物理接触、关键道具因果揭示 |

### 2. 机位物理高度与镜头倾角解耦

机位设置区分“物理高度”与“光轴倾角”两个独立维度，避免含糊笼统的“视角”：

- **机位物理高度（Camera Height）**：
  - 贴地机位（Ground Level）：机位距地 < 0.3米，强调步伐脚步、微观接触或地面压迫感。
  - 膝高/低坐姿（Knee Level）：约0.5–0.8米，东方榻榻米视角，稳定、克制、生活化日常。
  - 腰高机位（Waist Level）：约1.0–1.2米，古典稳重感，适合动作起势与桌面调度。
  - 眼高机位（Eye Level，默认）：与在场主体视线平齐（站姿约1.6米，坐姿约1.2米），平等交流。
  - 高位机位（High Level）：站立于台阶、城墙、二楼或摇臂上方，建立俯瞰观察视角。
- **摄影机光轴倾角（Tilt Angle）**：
  - 平视（Level）：光轴水平，日常中立。
  - 仰角（Tilt Up）：由下向上仰拍，普通人物决定、反抗、压迫、英雄威严或巨物尺度。
  - 俯角（Tilt Down）：由上向下俯拍，受挫、孤立、受审、包围与环境受限。
  - 荷兰角/倾斜（Dutch Angle）：光轴绕机身滚转15°–30°，表达心理失衡、剧变、危机或癫狂。

## 构图

- 三分：日常、等待、观察与心事，视线方向留空间。
- 中心：身份揭示、正面反抗等重要时刻；普通对白不连续用严格中心构图。第32节的主体清楚/偏中心不等于机械居中。
- 对称：仪式、家族对峙、审讯、议事，以中轴表达秩序。
- 框架：门窗、梁柱、帘帐表达阵营、窥视、阻隔或私密。
- 前景遮挡：肩膀、门框、树枝、帘幕或事件中的物体表达距离、危险与信息隐藏。为揭示或转场可暂时大面积/完全遮挡，写清解除方式与之后显露的信息；关键动作及结果仍需在适当时机可读。
- 对角线：奔跑、推搡、打斗、突变，来自真实动线。
- 纵深/双人同框：关系变化、站位压力、结果。先用中景建立两人位置，再切单人近景，保持轴线与前后层次。

### 构图安全留白三律（Composition Rules）

1. **视线留白（Look Room / Nose Room）**：角色视线投向画左，人物应置于画面右侧三分线；视线投向画右，人物应置于左侧三分线。视线前方必须保留至少 $1/2$ 画面横向空间，禁止面朝画框边缘贴边产生窒息感。
2. **运动留白（Lead Room）**：主体横向或斜向奔跑/行进时，行进前方画框必须保留充裕动线空间，避免让主体迎面撞向画框边缘。
3. **顶空留白（Headroom）**：中景与中近景人物头顶至画框上边缘距离，保持约为头部垂直高度的 $1/4$ 至 $1/3$；避免无故切削头皮，也避免留白超过半屏导致人物沉底。

“全景建立→中景动作→近景情绪→触发点特写→中景结果”是选择顺序参考，不是必须循环的五镜套餐。单人构图主体清楚，双手和必要道具处于可读区域；背景只保留地点、关系、身份、动作或光影所需结构。

## 有目的的运镜、有效切镜

详细路径和描写范例见 [描述细节与运镜设计](description-and-camera.md)。以下选择由本场信息任务决定，不把“克制”解释成所有镜头只能轻推或固定。

- 关键词、认知变化、情绪落点或爆点才轻推。
- 转头、抬手、小范围移动可以轻跟或轻摇，摄影机不抢表演。
- 用新镜号直接切换“谁说→谁听→谁反应→动作→结果→再反应”。每次切镜都有因果理由。
- 运镜字段按摄影机五要素一句话串成：起位（位置+视角/高度+景别+距主体公制距离）→ 观察/跟随目标 → 运动路径（推/拉/摇/移/升/降/环绕/固定/复合九类动词起头）→ 焦点变化或稳定焦点 → 结束构图（停留感）。固定机位允许稳定焦点，用人物、环境或信息变化承载时间；不强制焦点下沉。
- 变焦（Zoom）在描述中归于推拉范畴（注明“光学推焦 / 光学拉焦”），与物理机位推移（Dolly）清晰区分。
- 距离统一使用标准公制单位（米/m、厘米/cm），全面淘汰“步”等不确定口语单位。
- 复合运动（推+摇同时、移+升同时等）写明同步或先后关系、追踪目标与结束构图，例如“摄影机在距门1.8米处从门内中景向左缓移并微升，同时轻摇保持沈砚处于画面右侧，门框逐渐露出温知予，最终停在侧向双人构图”。
- 结束构图必含停留感（停留 / 切出 / 静止 / 续作），让下游明确这一帧是落点还是承接点。
- 避免无效绕拍、频繁推拉、无意义甩镜或倾斜、连续推近代替剪辑，以及同时堆叠多人独立复杂动作。极低/高位、荷兰角、手持或复合长镜有明确空间、尺度、失衡或信息揭示作用时可以使用，写清轴线、路径和可见结果；不因参考出现就每镜套用。
- 镜头切得紧凑，台词仍须听清；短反应不抢台词。单镜时长推荐一般不低于 2.0 秒（除特定爆点极速闪切外），避免产生 AI 难以执行的无意义超短碎镜。张力来自人物、空间与因果，不靠无意义惊吓、血腥细节或视觉噪音，也不声称能保证平台审核通过。
