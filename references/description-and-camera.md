# 描述细节与运镜设计

在写画面和运镜前读取。本文件只保留可复用的描写、可见性与摄影机判断方法。按当前剧情与空间作选择，不默认加载完整创作案例；实际交付仍按既有格式组织10.0–15.0秒段落、精确加总并保留原文。

## 1. 描述手法：让一个变化引出下一个变化

先判断这一镜让观众看见或理解什么，再用连续叙述写清：

**初始可见状态与空间关系 → 触发/发力 → 接触、轨迹或遮挡变化 → 落点与反馈 → 当前信息和结束画面。**

这是一条检查思路，不要求输出五个栏目，也不要求所有镜头发生动作。等待、凝视、不回应时，变化可以发生在环境、声音或被观察对象上。

- **用行为显示选择。** “一边逃一边捡，直到威胁逼近才松手”比单独写“贪财又害怕”更能表现性格。行为必须来自原文或已授权的设计，不能为立人设新增剧情。
- **按物体的去向写过程。** 交接、变形、散落、破裂说明从哪里离开、经过哪里、在哪里成为下一状态，避免主体或道具无依据复制、消失、瞬移。
- **用遮挡顺序揭示信息。** 先被门帘、物体或前景身体挡住，再随移开、分离或运镜显露后方对象。写清遮挡物、覆盖范围、解除原因和揭示内容；隐藏不能使关键因果永远不可见。
- **把抽象感受落在可见后果上。** “沉重”可落在关节缓慢承重、身体压低、接触面受压或沙尘被带起；“力竭”可落在撑起失败、手臂失去支撑和动作停止。选择当前事件有依据的后果，不把这些动作当作固定表演套餐。
- **让环境参与事件。** 尘烟遮住远处、门口限制通行、衣物受风、硬物相撞等须有当前作用。只增加“空气感、电影感、史诗感”不能替代空间和动作。

叙述顺序与观看顺序一致。先被遮住的对象不提前当作已可见主体；角色尚未知道的信息不通过新增表情或动作提前泄露。

仅当主文件已判断为需要持续攻防的特殊打斗段落时，补读 [特殊剧情下的连续打斗](special-combat.md)。其中的恢复支撑、受击回攻与跟随接触路径不推广为普通动作的固定流程。

## 2. 细节程度：关键处细，非关键处收

不设每镜最低字数。一个核心动作可以写得充分，静默镜头也可以简洁。镜头越复杂，越应把文字用于动作的不同阶段与因果，而不是重复近义词。

对需要观众感受力量、痛苦、迟疑或形变的重点动作，可以细到指尖支撑、关节承重、肩背牵动、衣料绷紧、硬物变形、细小碎屑和声响；每项需在景别中可读，并共同服务同一核心动作。“一主动作加少量表演变化”不是字数或细节上限，也不意味着每镜只准写一处身体反应。

| 层级 | 写什么 | 如何取舍 |
| --- | --- | --- |
| 叙事与连续性必需 | 可见主体、必要相对位置、关键持物、动作方向、触发点、结果和信息变化 | 保留到能判断前后相容；不能被氛围句挤掉 |
| 让画面可信的细节 | 发力部位、重心、接触点、惯性、材质响应、遮挡与显露、光源和空间层次 | 集中在当前动作或信息重点，不逐项堆满 |
| 氛围和微动 | 风、头发、火苗、远处人影、环境声、细小反光 | 选有区别的少量细节；不能抢走视觉和听觉中心 |

### 可见范围约束

- 近景要读清什么就保住什么；关键手部/道具低于取景边界时，调整景别或设计有依据的补镜，不能用文字把画外动作当作观众已看见。
- 背影写肩背、步态、重心与路径；远景写轮廓、队形、距离和规模。不同时要求看清背影人物眉眼、极远主体指尖或胸部以上画面中的裤腰。
- 细节精度随可见性变化：远处兽群可以先只是暗色带，切换到更近视点才出现个体结构。不能同一画面既坚持只能看见剪影，又要求分辨表面微纹。
- 材质、身体和动作写“画面”；环境光源、空间材质、空气与成像写光影字段，继续遵守原有字段边界。

### 角色外观与服装解耦设计（分镜与美术资产并行制作规范）

在工业化 AI 短剧制作中，分镜脚本往往与角色美术资产（三视图、立绘、参考图）同步并行推进。若在分镜提示词中写死角色的服装颜色、刺绣、版型（如“浅粉交领长裙”），一旦下游美术参考图定稿为其他款式（如“淡青色窄袖襦裙”），图生视频扩散模型（即梦/Seedance）会发生严重冲突，导致色块闪烁、衣服颜色随机跳跃或面部身体形变。

- **解耦核心准则**：**外观归参考图，提示词管物理受力与动作**。
  - **彻底留白项（交由参考图/资产卡负责）**：具体色彩（粉白、黛蓝、墨黑）、花纹图案（云纹、刺绣）、具体形制（对襟、琵琶襟、交领）、特定材质（织锦、粗麻）。
  - **重点强化项（分镜提示词的核心职责）**：标准角色名、走位动线、肢体手势、视线指向、神态与生理微表情，以及衣物受动作或环境影响的**物理受力与形态响应**（如衣摆翻动、袖口受风、前襟抓紧、衣褶受压、布料湿透贴身等）。
- **换装与状态改变**：剧情需要换装时，出场人物使用功能性后缀标注（统一为“角色名-造型名”，如 `苏莞-换装后` 或 `苏莞-大红嫁衣`），画面只交代脱/换衣物或穿戴动作，具体新外观交由对应的新参考图承接。

| 场景需求 | 冲突写法（写死外观 · 极易打架） | 解耦写法（只写动势 · 自由换装） |
| :--- | :--- | :--- |
| **角色登场** | ❌ 苏莞身穿**月白对襟粗麻襦裙、腰系深青布带**，快步走入柴房…… | ✔️ 苏莞双手提着木桶快步走入柴房，身姿清瘦，**衣摆随步态前后晃动**，视线投向画右…… |
| **打斗/奔跑** | ❌ 陆野身穿**黑布短打、右臂缠皮质护腕**，挥拳向前冲刺…… | ✔️ 陆野眼神发狠，挥臂向前猛冲，**袖管受风鼓胀**，右拳砸向桌面…… |
| **情绪崩溃** | ❌ 温知予跪坐在地，**粉白裙裾**散在地面，**双手死死抓着衣角花纹**痛哭…… | ✔️ 温知予跌坐在地，**双手死死攥紧前襟衣料**，指关节发白，前胸剧烈起伏…… |

### 状态锁定与自然变化

区分三个层面：**持续锁定的身份/位置/状态、允许的环境或身体微动、事件触发后的变化**。

例如角色躯干和表情静止时，风仍能吹动头发；机器人面罩在触发前为眼睛，触发后切换问号；固定摄影机可以观察环境变化。不要先写“全程任何部分都绝对静止”，后面又要求转头、变形或运动。

独立生成的每段重述必要状态与风格；同段内已经明确的事实不必在每句重复。重复用于身份和连续性锚定，不用于增加文字长度。

## 3. 运镜先决定信息任务

先问：**摄影机为什么现在动，移动后多看见/少看见什么，最后停在什么信息上？** 回答不出来时，优先稳定观察；不为满足格式强造转焦、轻推或旋转。

沿用单行五要素：**起位与距离（标准公制） → 观察/跟随目标 → 路径 → 焦点变化或稳定焦点 → 结束构图与停留方式**。
运动路径使用推、拉、摇、移、升、降、环绕、固定、复合九类动词起头。标题保留三个纯标签，运镜字段不写时间码、秒数或百分比。距离统一使用“米/m、厘米/cm”公制单位，全面停用“步”。

| 方法 | 适用的信息任务 | 必须说明的区别与细节 |
| --- | --- | --- |
| 固定（Static） | 等待、冷幽默、压迫或主体自行进出 | 摄影机不位移，焦点可稳定；人物和环境微动自然呈现 |
| 推（Dolly In / Zoom In） | 接近线索、放大情绪、解除遮挡或揭示关系 | **区分物理推与光学推**：物理推（Dolly In）伴随前后景视差与纵深展开；光学推焦（Zoom In）机位不动、背景视角压缩。写清谁/什么始终是空间锚点 |
| 拉（Dolly Out / Zoom Out） | 揭示环境规模、退出版面、孤独疏离 | 物理拉远（Dolly Out）显露更多周围物理障碍；光学拉焦（Zoom Out）视野扩张但透视不变 |
| 定点摇（Pan / Tilt） | 主体绕机位经过、观察方向转移、上下巡视 | 机位不动，光轴水平左右横摇（Pan）或上下俯仰（Tilt）；主体远近变化时画面大小自然改变，不暗中做推拉 |
| 横移/跟移（Track / Truck） | 显露前后层次、跟随路径动线、经过出口 | 摄影机与主体的方向、相对物理距离与避让；产生横向视差，不把平移误写成三脚架原地摇镜 |
| 升（Pedestal Up / Boom Up） | 从低处窥视升至全局掌控、傲然挺立、威压反转 | 机位沿垂直轴向上平移升起；交代起始高度与终止高度，显露更广视域或主体全貌 |
| 降（Pedestal Down / Boom Down） | 从宏观建筑降至人物微观、压迫降临、受挫受制 | 机位沿垂直轴向下平移降低；交代下沉落点与贴近的主体部位 |
| 环绕（Arc / Orbit） | 空间全貌巡检、多方对峙、心理眩晕与时间停滞 | 明确围绕哪个主体或中心道具旋转、旋转角度（如90°/180°环绕）及避让路径 |
| 连续复合（Compound） | 多个先后相因的节拍、跨维度运镜 | 哪些运动同时发生（如“移且升”、“推且摇”）、哪些先后完成、何时停稳；一镜内无真正切镜 |

### 运镜速度曲线与节奏（Camera Easing）

为避免 AI 视频模型生成出机械匀速或急刹穿模的镜头，在运动路径后可加入速度质感修饰：
- **缓入缓出（Ease In / Ease Out）**：启动柔和，末端带有平滑减速缓冲停稳，最适合日常情感、舒缓对白与优雅叙事。
- **快推急停（Snap Push / Whip Freeze）**：起势迅猛，在信息点或惊愕瞬间骤停锁定，用于笑点、爆点、惊恐反转。
- **恒速行进（Linear Tracking）**：无加减速的机械平稳滑动，用于客观审视、科幻工业感或命运冷酷感。
- **手持微幅呼吸感（Handheld Breathing）**：区别于剧烈颠簸手持，带有有机呼吸感的微小机动，消除纯三维渲染的死板僵硬。

### AI 视频生成特性与焦点转移（Rack Focus）避坑提示

- 当前扩散模型（即梦、Seedance、Kling等）**无法稳定渲染真实的物理跟焦与光学虚焦拉风箱过程**。当提示词过度强调“焦点从前景 A 缓慢拉至后景 B”时，AI 极易把虚焦过程误判为“画面融化重组”或产生形变噪点。
- **最佳实践**：在单镜头内，优先通过**摄影机物理位移（如推近、跟移越过遮挡物）**或**角色先后动作起势**来转移观众视觉重心；若需彻底切换焦点对象，**优先通过直接切镜（分镜切换）实现**，降级对单镜内细微 Rack Focus 的过度依赖。
- 焦点字段以“焦点稳定在具体主体”或随物理推移“自然保持在主体景深”为主，确保生成成功率。

同一连续场景中入画人物组合或可见范围改变时，按主文件条件读取 [群像空间与取景连续性](group-continuity.md)，从原占位核对当前取景，不以景别标签代替实际可见范围。

## 4. 运镜的空间检查

1. **地标固定。** 用门、墙、轨道、桌子等建立世界位置。摄影机转向后，区分世界方向与当前画面左右，不能把“镜头右后方”当作始终不变的世界坐标。
2. **视线不穿实体。** 从机位向主体和远景检查遮挡：近处高墙填满正后方时，必须解释通过哪里看见远处地平线；需要崖口、侧向视线或重新建轴时明确设计。
3. **距离和比例相容。** 固定位置及焦距时，主体靠近会变大、远离会变小；恒定画面比例需要相应摄影机/光学条件。构图比例是阶段目标，不在自然远近运动中强锁全程比例。
4. **焦段服务画面。** 广视角近距离可强调纵深与前景，幽闭也可来自窄空间和边缘遮挡；不把12mm等同于空间压缩。具体焦段有明确作用或已确认设置时才写，不当作电影质感口令。
5. **尺度有参照。** 用人、门、地形和其他已知物体建立体量。变形时分清主体尺寸、球径、身体宽度与展开足展；如果允许缩放，依据项目规则说明，既不默许无意跳变，也不擅加现实守恒限制。
6. **遮挡能恢复。** 用帘幕、物体或前景过镜结束/转场时，明确遮挡前后的人物、持物、造型和运动状态。换装属于已授权设计时，变化项与锁定项分别写清。

## 5. 声音与细节同步

按当前镜头选出环境底层、关键事件声、必要细节拟音。给声源、进入/退出时机、距离和强弱关系，不要求所有细微声音同时清楚。

- 接触、滑落、脚步、撞击与变形各有发生条件；声音随动作结果出现，不先于实际接触无依据响起。
- 远距离繁忙街景以环境和重要事件为主，衣料细擦不自动比近处车流更突出；主观听觉强调必须有叙事依据。
- 笑声、脚步或对白可跨镜衔接。同一声笑的表演连续，切换内外景时直达声与回声仍可随空间变化；不要为连贯复制一次完整笑声或整句台词。
- 冷幽默的短促提示音与之后沉默可以形成落点，不为“声音丰富”叠音乐、旁白或额外反应。
- 人物音色、非语言发声和地域口音分别描述。一次干呕不能代替已验证的方言表现，不能为了显示口音新增台词。

## 6. 交付前人工复核

- 核心细节是否让观众看懂动作、关系或信息变化；能否删去没有新增作用的同义强调。
- 当前景别能否看见所写部位、接触点与关键道具；光影字段是否混入人物。
- 相邻状态、物体去向、遮挡顺序和尺度是否相容；暂时隐藏的信息是否按原文顺序显露。
- 运镜是否有信息作用，路径是否能走通，定点摇镜与移动是否分清，主体比例是否随距离合理变化。
- 固定镜头是否允许有价值的等待与稳定焦点；连续长镜是否依次完成动作而非同时堆叠；真实切镜是否另立镜号。
- 声音距离与事件同步是否成立，沉默是否有意义，时长是否支持动作和台词。

这些属于语义复核；结构校验通过不能证明细节有效、运镜可行或成片质量。
