# 制作控制与执行策略

本文件用于复杂项目、批量生产或需要跨镜连续性的场景。默认交付仍遵守 `output-qa.md` 的固定分镜格式；本文件提供内部决策、风险检查和用户明确要求时才展示的制作控制卡。

## 1. 景别策略 Profile

景别由项目目标、场景任务、对话密度、空间复杂度和奇观规模决定，不设固定比例配额。可先选一个 Profile，再按镜头任务调整。

默认固定机位、按信息节点硬切调整取景，以剪辑形成略快节奏，避免连续重复同一景别、视角和构图；不把某个 Profile 理解为全段只用一种景别。切点、估时参考与长镜保留条件见 [景别切换与观看节奏](directing-performance.md#景别切换与观看节奏)。

| Profile | 主叙事景别 | 空间建立 | 情绪/信息强调 | 适用项目 |
| --- | --- | --- | --- | --- |
| 对话表演型 | 中近景为主，近景高频 | 中景交代人物关系 | 特写落在触发点 | 对话密集、人物关系、情绪表演 |
| 空间叙事型 | 中景为主 | 远景/全景建立空间和规模 | 特写落在关键物件、眼神或动作结果 | 世界观展示、漫剧、场景转换 |
| 动作奇观型 | 中景承载动作结果 | 远景/全景建立尺度与动线 | 特写落在冲击、接触、关键道具 | 追逐、战斗、变身、机械奇观 |

- 单镜可以发生景别变化，但必须写清起始取景、变化原因和结束取景。
- 中景不是默认答案；只有当前镜头需要同时交代人物关系、动作过程和空间位置时才优先。
- 全景和大远景只在空间、规模、队形或奇观本身具有叙事价值时使用。
- 特写和大特写只落在触发点、信息点或情绪落点，不连续堆叠。
- 若用户已有项目景别偏好，以用户要求覆盖本表。

## 2. 参考素材清单

参考素材用于确认身份、妆造、环境、空间、道具、色彩和声音，不默认使用 `@[...]` 平台 token，也不默认绑定首帧。

推荐格式：

```text
参考素材：
- 角色图（林晚-夜班造型）：身份、发型、围裙、服装和年龄感。
- 场景图（便利店柜台视角）：空间布局、柜台位置、地标和机位方向。
- 道具图（旧信封）：尺寸、材质、磨损和持握方式。
- 色卡（夜雨便利店）：环境色、冷暖关系和材质参考。
- 音色（V001 陆川）：年龄听感、音高、音质、语速和地域口音；参考音频或 TTS Voice ID 待配置。
- 故事板/九宫格：动作顺序、构图和镜头关系。
```

- 只采用已确认的素材用途；未确认部分写明缺口，不编造引用。
- 同一资产使用稳定标准名，原文台词中的称谓不强制改名。
- 场景资产按“大地点-子区域-具体空间”命名，空间层级统一用半角短横线 `-` 连接，例如 `威北将军府-听雪轩-主卧`；层级按实际地点取舍。场景字段、图片清单及连续性记录沿用同名，时间与内外景单独标注，不计入基础地点名。
- 角色图按 [原小说对照与分期造型](novel-costume-continuity.md) 匹配当前时期与衣着状态：记录剧本场次、小说出处和对应造型名；同一人物的不同造型分别计数，不能用一张泛角色图代替所有时期。工作造型记录不默认作为新增交付物。
- 若某平台确实需要 `@` token、首帧或尾帧，由用户明确要求后另加平台适配说明，不写入默认格式。

## 2.1 角色音色卡与跨镜绑定

有对白、OS、旁白、电话、隔门发声或需保留身份的非语言发声时，按 [角色音色分析与跨镜绑定](voice-consistency.md) 建立角色音色卡。音色参考不计入9张图片预算。

```text
角色音色卡
- V001｜林晚｜成年女声·中低音·轻微沙哑·语速偏快
  语言习惯：句尾短促，质问时停顿靠后
  情绪边界：生气时压低音量，不变成尖锐高音
  依据与置信度：原文职业与对白节奏；推断
  绑定方式：TTS Voice ID：待配置；参考音频：待配置
```

- 分镜的 `台词/声音` 字段使用 `标准资产名【V001｜基础音色描述】`，每个含对白镜头都重写，不依赖前镜。
- 同一角色跨镜保持同一 V-ID 和同一基础描述；情绪、哭腔、受伤、压低等临时状态写在锚点外。
- 文字锚点只能约束，真正绑定还需参考音频、固定 TTS Voice ID、同模型种子或后期统一配音。不得声称未配置的素材已完成核验。

## 2.2 参考图预算与取景控制

**一个独立生成视频（默认对应一个分镜段落）的全部参考图片合计最多9张。** 这是生成前的硬性执行条件；不能把超额仅标成风险后直接交付为可执行段落。

### 按实际图片计数

- 内部建立“图片/资产标识｜用途｜对应角色、造型或场景｜使用镜号”的清单，取全段各镜所需图片的并集。同一张图跨镜复用只算1张；同一资产使用多张图、不同造型/实质状态或独立视角时按实际张数计算。仅有资产需求而图片尚未制作时，先计入计划名额并标明缺口，不能因缺图而计为0。
- 角色图（含需视觉参考的群演）+ 场景图 + 道具、色卡、故事板及其他图片 ≤ 9张。1张场景图时角色图最多8张；2张场景图时最多7张；其他图片继续扣减。不同地点或布置不能默认共用一张场景图，同一场景复用已确认图片则不重复计算。
- “场景在场人数”“出场人物数”“群演类别数”均不等于参考图片数。未发声的背景人物仍可能入画；“众人”“女眷”“宫人”“侍卫”等类别不能自动各算1张或免占预算，须落实实际入画对象及其参考需求。具名角色不能为省名额被降为无身份群演；不把多人拼贴成一张图规避独立身份参考。
- 完全不入画者可不占角色图片名额，其声音按原文保留，音频不占图片预算；背影、身体局部、倒影、影子和失焦背景中的人仍是画面内容，按所需外观参考计数，不能仅凭“不露脸/虚化”将其删除出预算。

### 先调整取景，再考虑拆段

- 排镜前确认每拍必须可见的主体、关键接触和必要反应，其余在场人物按最近位置保留。优先选择有空间依据的中近景、近景、特写、局部中景或正反打，改变观察角度和裁切，使非必要人物真实处于画框之外或被已有实体完全遮挡；不是只改景别标签。
- 同一视频内轮流拍摄不同人物并不会减少图片并集：即使每镜只拍2人，整段先后出现10个需要独立参考的角色，仍按10个角色的用图计算。检查每镜起始、运动途中及结束构图，防止拉远、横移或遮挡解除时新增未纳入预算的人物。
- 不用虚化、背影、隐去姓名或删除“出场人物”条目冒充不入画；不删必须可见的交接、冲突结果、身份揭示或关键反应。非关键人物仅在剧情允许其不入画时留在画外，原有对白可按空间关系成为画外声，不新增对白凑衔接。
- 若局部取景仍无法在9张内完成原文节拍，按自然动作、反应落点或真实场景转换重组相邻段落，必要时拆成独立生成视频，每段重新核对预算并保持10.0–15.0秒。不能将现有短段机械切成不足10秒的片段，也不能靠空镜补时长；确有冲突时说明具体冲突，不删戏或虚报合规。

### 取景变化不等于人物离场

- 内部逐镜记录在场/入画/画外名单、最近站位与姿态、持物、未入画的画框边界或遮挡依据，以及段末变化。遵守 [群像空间与取景连续性](group-continuity.md)，不为省图编造离场、换位、墙体或遮挡物。
- 连续动作以动作匹配、视线、既有声音与空间地标硬切衔接；离场、追到、押送和换场到达按原文事件与实际时间更新。人物重新入画时继承最近位置、朝向、衣着状态和持物，不能凭切镜瞬移、复位或突然增减。
- 定稿后反查所有“画面”“运镜”及光影字段：入画人物有相应参考安排；整镜未入画者的姓名、站位、动作及“在画外”等说明全部删除，不能通过视线/对话关系重新引入。可见主体只写视线方向及反应；必要画外发声仅放“台词/声音”，未入画人物的连续性只留内部名册。不让“众人”承担模糊的身份与站位。

## 3. 复杂度闸门

在排镜和输出前检查以下风险。风险高时先拆镜或降低同时动作，不要靠增加形容词硬压。

| 风险信号 | 默认处理 |
| --- | --- |
| 画中画、监视器、镜子、手机 BTS、舞台中的舞台 | 明确外层/内层画框边界、焦点、声音来源和转场；必要时拆成两个镜头 |
| 同一镜头超过 2–3 个独立复杂动作 | 保留主任务，其余动作改为反应、结果或独立镜头 |
| 同一段落超过 4 次硬切 | 检查是否可按空间或动作回合重新分段 |
| 同一段落跨越多处不连续时空 | 在真实切换处拆段，或明确新场景首镜 |
| 一条提示词同时要求“一镜到底”和多次硬切 | 区分“单次生成连续”和“最终剪辑连续”，不能混写 |
| 参考素材用途不清、重复或未核对实际入画需求 | 按图片标识、用途与镜号整理清单，合并真实重复项；主次或局部用途不豁免计数 |
| 同一视频所需角色、群演、场景与其他图片合计超过9张 | 先按2.2调整真实取景范围；仍超额则重组相邻节拍或拆段，保留原文与连续性，不降格具名角色 |
| 多人同时完成不同复杂动作 | 先写主行动线，再用反应或结果镜补足 |
| 同一群像场景中可见人物组合变化，来源不明 | 在内部名册核对实际入退场、取景与遮挡；实际入退场补必要衔接，仅因取景不再可见者不逐人写入成品 |
| 整桌/全景可见，但画面人数与场景在场名册不符 | 按原占位补足应可见人物，或选择有空间依据的局部取景；未覆盖人物留内部记录，不用画外备注解释可见空位 |

仅对已按主文件条件启用的连续打斗：一次进攻、相应格挡/受击及其必要反应，可按一条互为因果的动作链评估，不等同于多人同时进行互不相关的独立复杂动作。仍需逐项核对接触、支撑、时间与取景；动作链过长或不可读时拆镜，不以“连续打斗”为由豁免复杂度检查。

风险等级：

- **低**：单主任务、单次道具交接、少量对白、无嵌套画框。
- **中**：2–3 个连续动作、一次硬切或匹配剪辑、少量参考素材。
- **高**：嵌套画框、多人复杂动作、多次硬切、跨时空、大量参考素材、群像人物组合跳变或整桌人数不匹配；优先拆镜或拆段，若用户坚持单段则明确风险。

## 3.1 群像场景连续性卡

饭桌、会议桌、炕桌、围坐、车厢、队列等固定占位场景，使用以下内部卡：

```text
群像连续性卡
场景：<当前场所与连续区域>
固定地标：<需要跨镜识别的地标与方位>
座位图：<人物标准名对应的位置、朝向及占位范围>
桌面道具：<当前相关道具与持有者>
本段可见范围：<整桌或局部；按当前机位实际判断>
场景在场：<实际在场人物名册>
本段入画：<各镜可见人物的合并名单；逐镜变化另记草稿>
本段出场：<本段实际发声或有关键行为的人物>
画外在场：<未入画者及其相对机位位置或完全遮挡依据>
入退场：<有剧情依据的变化；没有则明确无人离场>
参考图预算：<场景、角色与其他图片的实际合计，最多9张>
场景参考：<实际张数>张｜<已确认的场景图，逐张列出>
角色参考：<实际张数>张｜<按整段可见需求列出角色/群演造型图片>
其他参考：<如有也占总预算>
起始状态：<承接最近可确认的位置、姿态与持物>
结束状态：<本段动作之后的真实状态及下一段需继承的变化>
```

规则：

- `场景在场` 记录空间里实际有谁；`本段入画` 记录画面可见者；`本段出场` 只记录实际说话、关键动作或关键反应者。
- 新角色实际进入已建立空间，须有入口、揭示或有依据的画外声音；实际离场须有剧情依据并更新状态。切镜、取景或遮挡造成不再可见，只在内部核对，不能机械要求成品交代每个人的画外位置。
- 整桌/全景可见时，本段入画人数必须与场景在场人数相容；空座必须有原因。
- 相邻段落用结束状态和起始状态交接，可用门口声、椅子移动、脚步、画外呼唤或视线连接。
- 参考图预算按2.2核对：场景、角色/群演和其他图片按整段实际图片清单合计不得超过9张；场景图数量按实际需要，不固定为1张。
- 同场跨段入画组合或可见范围改变、或重新展示完整占位区域时，读取 [群像空间与取景连续性](group-continuity.md)。名册只是状态记录，画外与空位仍须在真实取景和运镜路径中成立。

## 4. 时间节拍

简单镜头只写完整动作过程，不强制时间码。复杂镜头可在“画面”字段内部用分句标出节拍，不新增输出字段。

示例：

```text
画面：0–1.2s陆川从内袋取出信封；1.2–3.0s信封落到柜台上并说台词；3.0–4.8s林晚视线从信封抬到陆川脸上。
```

- 节拍必须按真实动作、台词和反应分配。
- 节拍之和不能超过镜头时长。
- 运镜字段仍不写秒数；镜头标题只放总时长。
- 不为凑秒增加空镜、重复反应或无关动作。

## 5. 转场与连续性语法

### 只用硬切

所有镜间画面连接只用硬切，含跨段、跨场及闪回；每个有后继镜头的镜尾标“硬切”。不使用叠化、淡入淡出、溶解、闪白、黑场过渡、擦除、遮罩、遮挡转场、甩镜转场、变形或画框穿越效果。

动作匹配、视线衔接和声音自然跨镜属于连续性方法：仍是前镜直接硬切到后镜，声音可连续而画面无混合、渐变或过渡帧。真实物体遮挡或剧情内灯光改变按原事件保留，不把它加工成切镜特效；不新增专用转场音效。真实切镜另起镜号，不藏在单镜运动中。

### 默认连续性记录

不默认使用首帧锚定，改用文字状态：

```text
起始状态：林晚在柜台内侧，右手拿抹布，身体朝向门口。
结束状态：林晚双手压在信封两侧，门已合拢，陆川已离场。
```

- 每个独立段落重述必要状态，不写“同前”。
- 记录人物姿态、位置、朝向、视线、手部/道具、服装和空间地标。
- 画中画必须写清外层与内层各自的人物、时间和声音来源。

## 6. 声音槽位

按镜头需要选择，不要求每项都出现：

1. 环境底层：风、雨、车流、人群、室内底噪。
2. 关键事件声：门铃、电话、撞击、开关、机械启动。
3. 动作拟音：脚步、衣料、纸张、金属、接触和摩擦。
4. 对白：画内、画外、电话、隔门，标明发声者与听者。
5. 非语言发声：呼吸、哭笑、喘息、干呕等原文允许的声音。
6. 静音/留白：有意沉默、声音抽空或延迟。
7. BGM：明确使用、仅局部使用或明确不要。
8. 声音桥接：跨镜延续或提前进入的声音。

## 7. 负面约束预算

每个段落优先保留 5–8 条真正影响结果的限制，按优先级分组：

- 身份：不要换脸、不要换发型、不要换服装（在解耦模式下，具体服装形制与色彩由角色参考图完全锁定，提示词不得添加冲突的服装色彩与款式描述）。
- 道具：不要让关键道具消失、换手或改变尺寸。
- 连续性：不要让姿态、位置、朝向或空间方向跳变。
- 表演：不要新增台词、不要做无关口型、不要夸张化。
- 镜头：不要隐藏切镜、不要同时堆叠多人复杂动作。
- 声音：不要让环境声盖过对白、不要无依据加 BGM。

不要在每个镜头重复同一组“不要”。段级能解决的，不逐镜重复；只有本镜特有风险才写本镜限制。

## 8. 统一术语

### 景别

大远景、远景、全景、中全景、中景、中近景、近景、特写、大特写。

### 运镜

推、拉、摇、移、升、降、环绕、固定、复合九类标准动词起头；变焦在描述中注明“光学推焦/光学拉焦”；默认固定，景别主要以硬切切换；必要运动才描述速度曲线，少量推拉须有独立作用；镜头标题仍保持景别/视角/构图三个纯标签。摄影机起位距离一律使用公制单位（米/厘米），不用“步”计量；人物站位与动作步数按 [距离、站位与动作步数](description-and-camera.md#距离站位与动作步数) 区分处理。

### 转场

画面只用硬切；动作匹配、视线承接、声音桥接仅作连续性衔接，不生成转场特效。

### 声音

环境底层、关键事件声、动作拟音、对白、角色音色锚点、非语言发声、静音、BGM、声音桥接。

同一份交付内保持术语一致；不要在同一镜头标题混用“中景偏特写”“广角全景”等多个未定义标签。需要表达变化时，在画面或运镜中写起始和结束状态。
