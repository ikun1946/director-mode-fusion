# 特殊剧情下的连续打斗

本文件是条件性扩展，默认不启用。先按主文件的“特殊打斗的条件启用”判断，再读取本文件；高张力、争吵、出现武器或动作奇观型景别，都不自动等于需要持续近身连击。

## 1. 启用与退出

| 剧情依据 | 处理 |
| --- | --- |
| 用户明确要求持续近战、连续攻防、追击反扑或高强度格斗高潮 | 仅在指定打斗范围启用，动作内容和强度仍服从已授权剧情 |
| 原文明示多轮近身交锋、边退边挡后反攻、借环境改变攻防等连续过程，而且这些过程承担追逃、胜负或局势变化 | 可在对应动作段落启用，补足执行所需的重心、接触和摄影机调度 |
| 只有“发生冲突”“打了一架”“动作场面”等概括，没有持续攻防依据 | 使用通用动作规则；不能自行升级为长时间连击 |
| 普通争吵、单次推搡或掌掴、喜剧跌倒、一般追逐、枪战或远程施法 | 不因场面激烈自动启用本规则；按实际动作与叙事任务处理 |
| 原文角色受制、失去反抗能力、负伤倒地、主动停手、说话或战斗结束 | 保留这些结果；不得为维持“不断反击”新增能力、恢复或追打；相应连续动作结束后退出本扩展 |

工作草稿可用一句话记录“哪段原文/用户要求需要表现什么连续攻防”，不增加成品字段，不把整部作品改成同一种动作节奏。不新增台词、胜负、关系、伤势或关键环境破坏。只补足既有动作成立所必需的支撑、转体、落脚和空间过渡。

## 2. 连招依靠身体状态衔接

每个关键交锋按需要写清：**相对位置与支撑 → 发力方向 → 命中、格挡或落空 → 重心与姿态变化 → 恢复支撑或借势转向 → 下一次攻击、追击或退出。** 这是一条因果检查线，不要求固定招式数、镜头数或每击都写满全部环节。

- 上一击的结束姿态就是下一击的起点。后仰后如何回正、横滑后哪只脚踩实、翻滚后如何撑起、腾空后在哪里落地，应在影响下一动作时交代。不能仅用“顺势、立刻、借着”代替身体过渡。
- 说明必要的攻击部位、目标部位、方向和防守方式；左右手、支撑腿与躯干朝向影响衔接时写明，避免同一肢体同时承担互不相容的任务。手臂成为支撑点前，要先有触地或扶靠动作。
- 把位移接进攻防：一方被推退，另一方怎样追入；一方下潜，怎样从另一方手臂内侧起身；转身前后谁面对谁。不能在下一句默认双方重新正面站好。
- 角色有能力且剧情允许时，受击的侧折、回弹或旋转可成为反击起势；伤势、体力和胜负必须延续。受击反馈不能写完就清零，也不能让失去支撑的角色凭空发出完整重击。
- 按原文保留双方差异，如前压与闪避、短拳与借势转体、追击与脱离。双方同步出招只在有明确表现目的时使用，避免连续镜像动作抹平人物打法。

## 3. 命中、阻挡与惯性反馈

力度落在可见后果上。按接触部位、方向和本次强度选择少量有效反馈，不让每次碰触都成为全身腾空的重击。

| 接触或受力 | 可采用的反馈与后续检查 |
| --- | --- |
| 头部或下颌受击 | 头部沿受力方向偏转，肩颈和躯干随后调整；发丝继续沿惯性甩动，反攻前有重心回收 |
| 躯干或肋部受击 | 接触一侧受压、身体侧折或收腹，支撑脚补位；不能只甩头而躯干不响应 |
| 肩部受压 | 肩线下沉、上身倾转、承重改变，说明如何稳住或被迫下落 |
| 格挡、拳套或前臂相撞 | 防守肢体被推移、肘角变化、肩部承压，必要时带动步伐；若手臂顶到下巴，再表现头部反应 |
| 推击、扫腿与跌落 | 鞋底擦滑、支撑被撤走、落地缓冲或撑地滚动，交代下一次站稳或出招的来源 |

头发、衣料、链条等次级运动按已有角色资产选择，用来显示运动滞后与方向；不为演示效果给角色新增配件或锁定外观。出拳、接触、衣料受力、碎屑与拟音要在同一事件上对应，不能先爆出撞击效果再补一个未接触的拳头。

## 4. 让已有环境参与攻防

按原文和已建立的场景选择可利用的围栏、墙面、地面或柜体，写清**接触位置 → 受力方式 → 材质反应 → 对下一动作的影响**。例如借围栏蹬离要说明脚踏位置与离开方向；擦地滑移要看见鞋底、摩擦痕和失衡结果。

先判断环境作用是借力、阻挡、承撞还是限制退路，不为凑奇观增加设施、机关、破坏或电火花。灰尘、碎屑、围栏震颤、柜体凹陷等在发生后继续存在；后续镜头承接人物位置与环境损坏。地标以场景世界方位记录，摄影机绕到另一侧后，不把原先的画面右侧当成新的世界右侧。

## 5. 摄影机跟随动作，但保住接触关系

先决定这一拍要读清进攻、接触还是失衡后的局势，再选路径；不规定每拳切镜，也不规定摄影机全程高速运动。

- 关键命中尽量让观众读到攻击来源、接触点和受击方向。可用双人全景、中景、斜侧构图或清楚的过肩关系完成，不强制拆成三镜。单人反应或局部特写用来强调结果，不能长期替代双方真实交锋。
- 仍按主文件单行五要素写运镜：起位与公制距离、观察目标、路径、稳定焦点或必要变化、结束构图。画面写动作，运镜写观察路径，不另造字段或重复整段招式。
- 跟拳时说明沿哪个出拳方向移动，接触前后保留哪一名人物与受击部位；跟鞋底或贴地移动时，取景须包含所需落脚、扫腿或擦地关系。近身纵深靠人物错位、前景肢体和地标建立，不靠把另一人虚化到无法识别。
- 环绕交代中心、方向、幅度及结束后谁在前景；升降配合人物高度变化，说明先后顺序。“穿过两人之间”须有可通行的实际间隙和发生时机，不让镜头穿过躯干、紧贴交叉的手臂或实体设施。
- 区分连续甩摇与真实切镜。连续摇向另一张脸是朝向变化，摄影机连续移动到新位置也仍属同一镜；通过剪切切换观察位置时才使用新镜号。眼睛、配件、鞋底等细节插入若是剪切，也分别编号，不能藏在一条连续运镜里。
- 沿既有动作轴组织方向。环绕越轴可通过可见的连续路径完成，或用中性位置、人物走位建立新轴；不能在切镜后无交代交换人物左右与攻击方向。相邻镜头写清切出时的动作状态和切入承接点，不重演一次完整命中。
- 摄影机运动有强弱：追击可跟移，接触时可缩小幅度保住落点，位移扩大时再拉开或转向。剧情要求持续运动时，也可用小幅随动承接强烈冲击，不把“全程在动”理解成持续翻转、甩镜与震屏。

## 6. 时间、节奏与风格边界

- 先估算连招、落脚、翻滚、回身和环境接触的可读时间，再拆镜与组合段落。沿用主文件10.0–15.0秒段落规则；用户另定总时长时，按用户要求分配内部镜头。不要从案例继承30秒、16:9或30fps。
- 把快速衔接、破防和造成局势改变的重击区分开；用动作幅度、距离和摄影机速度变化形成节奏。连续反扑不等于每招都最大受击，也不等于禁止原文必要的说话、停手或败退。
- 超短接触特写仅在关键信息确实可读时使用，计入段落总时长；不能把需要数秒完成的身体动作塞进几个闪帧，也不能用模糊、全屏亮闪或密集切镜遮住全部关键接触。
- 高速拖影、方向残影、冲击构图夸张、短促亮闪或2D sakuga式节奏，只在用户或项目已明确采用相应风格时使用。是否启用连续打斗，与是否启用风格化强化分开判断；写实格斗可以只采用身体与摄影机规则。
- 不自动继承案例的超写实3D、酸绿/橙白闪光、无慢动作、无对白等设定，也不自动加入能量波。已授权的特效跟随动作节点，保住接触前后的可读性；碰撞前截断就不能同时描述已经发生的撞击破坏，除非明确是独立的风格化预示效果。

## 7. 仅对已启用段落复核

1. 原文或用户要求是否真的支持持续攻防；是否只在相应范围生效，没有给普通冲突加连招。
2. 每个关键交锋是否有可辨的攻击者、防守或受击者、接触与方向；反击是否有支撑与时间来源。
3. 上一动作的重心、伤势、位置与下一动作是否接续；环境损坏与道具状态是否保留。
4. 取景是否容纳关键肢体与落点；摄影机路径是否可通行，越轴有无可见过渡，剪切有无独立编号。
5. 时间是否容纳实际动作；强弱是否有区别，是否保留剧情需要的停顿、失败或结束。
6. 风格化效果是否另有依据；是否误把场景、人物外观、画幅、帧率或特定配色设成全项目默认。

结构校验只能核对编号、字段与时长等，不能证明攻防成立或摄影机路径可行。需要成品对照时参考下面的完整示例，不套用固定镜数与招式顺序。

## 8. 完整示例：连续动作中的接触与反击

以下只截取用户案例中“直拳—下潜上勾—格挡回弹—连拳—正蹬—旋踢—贴身反击”的动作链，示范13.2秒段落写法，并非重写原30秒短片。沿用已有角色资产，不新增服装设定、台词、胜负、配色特效或画幅。摄影机始终从围栏对面的开敞通道拍摄，不越过人物动作轴。

```text
段落1｜总时长：13.2s
场景：废弃高架列车维修站 日 内
出场人物：Vexa、Kaida
本段统一光影/质感：右后方日光穿过工业梁架形成条状阴影，灰蓝环境底色，混凝土地面有磨损与少量浮尘；后方铁丝网围栏保持可辨，空气中有逆光粉尘，关键接触所在景深清晰。

镜1｜3.2s｜中全景/平视视角/双人斜侧构图
画面：围栏在两人后方，Vexa位于画左、Kaida位于画右，双方相向处于出拳距离。Kaida前压打出左直拳；Vexa屈膝下潜，让拳头从头顶越过，随即蹬伸双腿、转胯从内侧顶出上勾拳。Kaida抬起前臂挡住，前臂受力回顶下巴，肩颈随之向后带动，头部后甩；Kaida后脚压住地面，开始借回弹把上身送回攻击距离，切出。
台词/声音：无台词；两人闭口，拳风掠过后接前臂碰撞的闷响，鞋底短促摩擦声贴近。
运镜：摄影机在开敞通道一侧·距地1.1米·平视·中全景·距双方约2.6米，看Kaida前压与Vexa下潜反攻，移随双方的短距离进退横向跟拍并小幅推近，保留双方头部与格挡手臂；焦点稳定在双方交锋所在景深；结束于Kaida头部后甩、前臂贴近下巴且上身开始回正的双人构图，动接动切出。

镜2｜3.0s｜中全景/平视视角/双人前后错位构图
画面：Vexa仍在画左，Kaida仍在画右；切入承接Kaida后脚承重、上身开始回正的瞬间。Kaida顺着回弹连续打出两拳，第一拳被Vexa抬臂挡住，第二拳撬开防守擦中面侧，Vexa头部向画左偏转，发丝沿受力方向甩出。Vexa后撤半步踩实左脚，收回头部并抬起右膝，沿两人之间的空档送出正蹬；Kaida收拢拳套迎向鞋底，在鞋底即将接触拳套时切出。
台词/声音：无台词；两人闭口，格挡闷响后紧接面侧擦击声，衣料与发丝掠动声低于接触声。
运镜：摄影机在开敞通道一侧偏Vexa左前方·距地1.2米·平视·中全景·距双方约2.4米，看Kaida的连拳与Vexa踩实反蹬，移随Vexa后撤同步退移并略向下摇，保持双方头部、抬膝与拳套同处画内；焦点稳定在双方攻击距离内；结束于Vexa右脚逼近Kaida合拢拳套的斜侧构图，接触前切出。

镜3｜3.6s｜全景/低位平视角/双人纵深构图
画面：Vexa在画左伸出右腿，Kaida在画右合拢拳套；承接上一镜鞋底逼近的瞬间，正蹬压中拳套，Kaida双臂被推回胸前、双脚向画右擦滑，鞋底带起浮尘。Vexa收回右腿向画右落步追入，前脚压住地面，转胯甩出旋踢；Kaida在滑移末端踩住后脚，屈膝低头，让Vexa脚跟从头顶掠过。Vexa踢出的腿开始回收，Kaida从其腿弧内侧起身逼近，切出。
台词/声音：无台词；两人闭口，正蹬撞击拳套的闷响后接连续擦地声，浮尘与细小碎屑随鞋底滑移扬起。
运镜：摄影机在开敞通道一侧·距地0.6米·低位平视·全景·距双方约3.0米，看正蹬命中、Kaida擦滑与后续低身闪避，移随Kaida向画右跟拍，Vexa旋踢时略拉开保留双方全身与腿弧；焦点稳定在两人及脚下接触区域；结束于Vexa收腿、Kaida由腿弧内侧抬起肩线的双人全景，沿起身动作切出。

镜4｜3.4s｜全景/平视视角/双人交锋构图
画面：Vexa仍在画左，旋踢腿回收落地，重心尚在转回；Kaida仍在画右，承接从腿弧内侧起身的动作，踏近打出贴身勾拳。拳头压入Vexa躯干，Vexa上身向内折弯、双脚短暂离地，衣料随躯干受压；Vexa左脚先落下接住重心，借落脚带动上身回转甩出肘击。Kaida以双拳套接住，肘部冲力把拳套顶向面前，肩部后让并连退两步缓冲。Vexa右脚跟进落稳，随即抬起拳头追入，双方仍保持明确间距。
台词/声音：无台词；两人闭口，躯干闷击、肘部碰撞拳套与先后落脚声形成主次，浮尘随脚步散开。
运镜：摄影机在开敞通道一侧·距地1.0米·平视·全景·距双方约2.8米，看Kaida贴身反击与Vexa借转体回肘，移随Kaida踏近小幅横移，命中时收小移动幅度保住躯干接触，随后随双方退进跟移；焦点稳定在双人交锋所在景深；结束于Kaida后退缓冲、Vexa落脚追入且双方全身可辨的构图，续作。
```

语义复核要点：四镜合计13.2秒；镜2在正蹬接触前切出、镜3接触后表现一次结果；Kaida的回弹、擦滑踩实与Vexa的落脚都为下一招提供支撑；全段保持同侧观察与左右关系。示例未展示围栏借力、柜体破坏或风格化亮闪，这些是有剧情依据时才选择的方法，不要求每段凑齐。
