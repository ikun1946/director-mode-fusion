# 角色音色分析与跨镜绑定

本文件用于有对白、OS、旁白、电话、隔门发声或需要保留身份的非语言发声项目。目标不是只写一句“声音低沉”，而是把发声身份、基础音色和跨镜绑定方式固定下来，使每个分镜提示词都能独立复原同一角色。

## 1. 建立发声者名册

先从本次完整剧本中列出实际发声身份，不把仅被提及、仅做反应或只有画面动作的人物混入：

- 画内角色、画外角色、电话/隔门发声者；
- OS、旁白、广播、群体领喊；
- 需要保持身份的笑、哭、喘息或其他非语言发声。

对每个发声身份记录标准资产名，并沿用项目已有的角色名映射。改名、别名或身份称谓不改变 V-ID。

## 2. 从剧本提取声音依据

优先使用原文能支持的声音信息：

- 年龄、身体状态、时代与生活环境带来的年龄听感；
- 职业、身份、教育经历和社交场景带来的语言习惯；
- 原文对嗓音、气息、口音、语速、音量、情绪控制的直接描写；
- 对白长度、停顿方式、常用句式和情绪变化；
- 他人对该角色声音的反应或描述。

对“低哑、清亮、鼻音、胸腔共鸣”等主观声学词，必须有原文依据、项目既定设定，或明确标为“设计拟定”。不要仅凭姓名、性别、正反派身份套用刻板声线，也不要凭空添加地域口音。

| 证据等级 | 用法 |
| --- | --- |
| 明确 | 原文直接写明，可写入依据 |
| 推断 | 由年龄、职业、身体状态或对白习惯合理推断，注明“推断” |
| 拟定 | 原文不足时为可执行制作做的声音设计，必须注明“拟定” |

分析阶段可在内部使用下表，不默认进入交付：

| 发声者 | 发声方式 | 原文依据 | 基础音色决策 | 置信度 |
| --- | --- | --- | --- | --- |
| 林晚 | 画内对白 | 职业、疲惫状态、短句节奏 | 成年女声·中低音·轻微沙哑·语速偏快 | 推断 |
| 陈默 | 隔门发声 | 嗓音低沉、说话停顿偏长 | 成年男声·低音·颗粒感明显·语速偏慢 | 拟定 |

## 3. 建立角色音色卡

每个发声身份使用唯一、稳定的 V-ID。编号至少三位，如 `V001`、`V002`；续作沿用原编号，不复用给其他角色。

```text
角色音色卡
- V001｜林晚｜成年女声·中低音·轻微沙哑·语速偏快
  语言习惯：句尾收得短，质问时停顿靠后
  情绪边界：生气时压低音量，不变成尖锐高音；哭腔不改变基础音高
  依据与置信度：原文职业、对白节奏与疲惫状态；推断
  绑定方式：TTS Voice ID：待配置；参考音频：待配置
```

- 基础音色锚点取 3–5 项跨镜稳定的特征：年龄听感、声部/性别听感、音高、音质、共鸣、语速节奏、口音体系等。
- 情绪、醉态、受伤、睡意、哭腔、喘息是临时发声状态，写在锚点外，不写进基础音色。
- 绑定方式只写真实存在且已确认的 TTS Voice ID、参考音频、平台音色或模型种子；缺失就写“待配置”，不编造路径、ID 或核验结果。

## 4. 写入分镜提示词

音色锚点只放 `台词/声音` 字段，不放进 `画面` 或 `本段统一光影/质感`。格式固定为在标准资产名后紧接全角方括号：

```text
台词/声音：林晚【V001｜成年女声·中低音·轻微沙哑·语速偏快】看着陈默说：“你早就知道，对不对？”窗外雨声压低。
```

- 同一角色在所有镜头使用同一 V-ID，并逐字复用同一基础音色描述；只允许在锚点外补充“压低声音、带哭腔、气息虚浮”等临时状态。
- 每个含对白的镜头都要重新写出锚点，保证该镜头被单独生成时仍然自包含，不能依赖“同前”或前一段提示词。
- 一个镜头有多个发声者时，每个发声者各自带锚点：

```text
台词/声音：林晚【V001｜成年女声·中低音·轻微沙哑·语速偏快】压低声线说：“别开门。”陈默【V002｜成年男声·低音·颗粒感明显·语速偏慢】隔着门问：“是你吗？”
```

- 画外、电话、隔门、OS 和旁白仍使用对应发声身份的标准名，例如“画外林晚【V001｜……】说”。不虚构为不同人物，也不因传播介质被改掉基础音色。
- 角色在同一作品中发生永久年龄阶段变化时，为新的声音阶段使用带阶段限定的标准资产名（如“林晚（老年）”）并分配新 V-ID，在音色卡中注明其与原阶段的关系；临时情绪变化不新建 V-ID。

## 5. 真正的音色绑定

文字锚点只提供语义约束，不能保证不同视频任务生成完全相同的嗓音。需要可复现绑定时，按可用能力选择：

1. 固定 TTS Voice ID 或平台角色音色；
2. 使用同一参考音频，并保持模型、音色设置和必要种子一致；
3. 使用支持音色参考的视频模型生成对白；
4. 先生成画面，再用同一配音身份完成后期配音与口型对齐。

如果平台不支持任何声学参考，应在交付中明确“仅有文字锚点，实际音色可能漂移”，不能声称已经完成音色锁定。

## 6. 一致性检查

交付前逐项检查：

- 每个实际发声身份都有唯一 V-ID，没有同名多 ID 或同 ID 多角色；
- 同一 V-ID 的基础音色描述跨镜逐字一致；
- 每个含对白的镜头都带音色锚点，且锚点紧跟在标准资产名后；
- 锚点包含 3–5 项稳定特征，不含临时情绪、受伤或哭腔等状态；
- 角色音色卡、分镜锚点和绑定素材三者一致；
- 未确认的参考音频或 Voice ID 明确写“待配置”。

需要确定性结构检查时运行：

```text
python scripts/validate_storyboard.py 分镜文件.md --check-voices
```

该检查只验证锚点格式、对白镜头是否带锚点、V-ID 与角色/描述映射是否冲突；不能验证实际声音相似度、生成模型是否遵循提示词或成片音色是否稳定。
