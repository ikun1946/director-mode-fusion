# 成品格式与质检

## 固定格式

每个段落按以下顺序输出；不添加独立镜间解释、导演分析或检查结果。复杂项目可在内部使用制作控制卡，但默认不把它写进交付；控制卡规则见 [制作控制与执行策略](production-controls.md)，角色音色规则见 [角色音色分析与跨镜绑定](voice-consistency.md)。

1. `段落N｜总时长：X.Xs`
2. `场景：具体地点 具体时间 内/外`
3. `出场人物：姓名、姓名`（无符合条件者写“无”）
4. `本段统一光影/质感：只描述环境和成像`
5. 逐镜重复：`镜N｜X.Xs｜景别/视角/构图`、`画面：`、`台词/声音：`、`运镜：`。
6. 有对白的发声者在 `台词/声音` 中使用 `标准资产名【V001｜基础音色描述】`；同一角色跨镜复用同一 V-ID 和同一基础描述，临时情绪写在锚点外。
7. 环境光确实变化时，允许在相应镜头“画面”后补 `本镜光影：`，不写人物。
8. 一段内真实切换地点、时间或内外景，在新镜头之前单独写 `场景：新地点 时间 内/外`。不在段首写双场景箭头，不命名“场景1到场景2”。同一连续镜头穿过同一场所的相连区域，可用具体上位场所名，在画面中按门口和路径交代区域变化；不把不连续时空冒充相连空间。
9. 两段之间用单独一行 `@`；镜号全程连续。新作品默认段落1、镜1；续作沿用已有编号。

运镜字段写法（SD 单行摄影机指令）：

```text
运镜：摄影机[起位·视角/高度·景别·距主体公制距离]看[主体]，[运动路径]；焦点[变化轨迹或稳定位置]；结束于[结束构图+停留感]
```

五要素按此顺序串成一句：起位（含位置/机高与视角/景别/距主体公制距离，摄影机定位不用“步”计量）→ 观察/跟随目标 → 运动路径（推/拉/摇/移/升/降/环绕/固定/复合九类动词之一，可带缓入缓出等速度曲线）→ 焦点变化或稳定焦点 → 结束构图（含停留感：停留/切出/静止/续作）。缺任一项应补回，不允许省略。固定机位可写“焦点稳定在具体主体”，不强制转焦；稳定焦点不是遗漏焦点字段。

用起始、变化和结束状态检查同一主体/空间锚点与连续性，输出仍为上述单行五要素。静默、等待和固定观察允许前后构图、姿态或焦点相同，不能强行制造变化。运镜字段内不放秒数、时间码、百分比、固定时间点，不写“接上个、同前、保持不变、继续推进”等抽象依赖语。镜头时长只放镜头标题。单镜时长推荐一般不低于 2.0 秒（除特殊爆点快剪外）。细节粒度和路径范例见 [描述细节与运镜设计](description-and-camera.md)。

## 输出前语义质检

| 检查 | 通过条件 |
| --- | --- |
| 原文覆盖 | 每段原句、动作、台词和信息揭示都有镜头对应，无概括、删词、漏段或擅自续写 |
| 节拍 | 按意图与情绪转折，段内有推进、落点和必要反应；不是凑秒 |
| 时间 | 台词听得清、动作做得完；每段（含尾段）10.0–15.0秒；所有标题等于实际镜头之和；单镜时长推荐一般 $\ge 2.0$ 秒（极速动作除外） |
| 场景 | 段首只有起始场景；切换在对应新镜之前；地点、时间、内外完整 |
| 人物 | `出场人物`只含实际发声、关键动作或关键反应者，角色身份具体，无被提及者混入；它不等于场景在场人物 |
| 案例读取边界 | 常规创作未把examples/成品当作默认上下文；格式结构固定，剧情、机位、镜数和动作按当前任务设计 |
| 群像取景（触发时） | 已按占位核对画框与遮挡，未入画有空间原因；运镜全过程和重新展示区域时的人物数量与最近状态相容，参考预算覆盖整段可见需求 |
| 群像层级 | 同一连续场景已区分场景在场、本段入画、本段出场和画外在场；出场人物少不等于场景里只有这些人 |
| 群像入退场 | 新角色有入口、揭示或画外声音；旧角色有离场动作、画外状态或连续性锚点；人物组合变化有因果 |
| 整桌/全景可见 | 画面人数与场景在场名册相容；空座有原因，未入画人物有画外声音、道具或明确离场说明 |
| 角色造型命名 | 需要区分的角色造型、年龄阶段或实质状态统一写为“角色名-限定词”，相关字段与参考素材清单命名一致 |
| 参考图预算 | 每段最多9张：场景1张 + 角色最多8张；同一角色不同造型分别计数，其他参考也占预算，总数不超9张 |
| 状态/道具 | 坐站蹲躺、位置、朝向、持物逐镜延续；改变有动作；跨段写全 |
| 对话与轴线 | 谁对谁说明确；严格遵守 180° 轴线；画左角色视线投向画右、画右角色视线投向画左，对视锁定防撞车 |
| 角色音色 | 每个实际发声身份有唯一 V-ID；同角色没有多 ID，同 ID 没有多角色；基础描述跨镜一致 |
| 音色锚点 | 每个含对白镜头都带锚点，紧跟在标准资产名后；锚点含3–5项稳定特征，不混入临时情绪或受伤状态 |
| 音色绑定 | 角色音色卡、分镜锚点、参考音频/Voice ID/种子信息一致；缺失素材写“待配置”，不把文字锚点冒充声学锁定 |
| 嘴型 | 无台词明确标注；无口部动作时闭口；OS/旁白/听者不做他人说话口型；原文自然口部动作及非语言发声完整保留 |
| 画面与景别 | 人体截取符合解剖基准（胸/腰/膝/锁骨）；机高与倾角解耦；关键动作有触发、接触和结果；动接动出入点连贯 |
| 构图留白 | 视线前方有 Look Room；移动主体前方有 Lead Room；人像头顶有适当 Headroom；避免主体贴边撞框 |
| 运镜规范 | 一句话含起位、观察/跟随、运动、焦点、结束五要素；运动路径使用推/拉/摇/移/升/降/环绕/固定/复合九类动词起头；区分物理推与变焦；带缓入缓出等速度曲线；摄影机起位距离使用公制单位（米/厘米），不用“步”计量；无时间码；切镜以新镜号表达 |
| 人物站位与动作步数 | 固定站位有清楚的参照与相对方位，必要时用公制近似距离，不强制数字化；“迈近一步、后退半步”等动作步数可保留，不机械换算或仅因含“步”判错；接触、避让与遮挡相关动作的方向和落点明确 |
| 光影与景深 | 自然低饱和、有来源光线、背景可辨；景深层次可控（全景深/环境浅景深/极浅景深）；字段不含人物 |
| 环境微动取舍 | 已结合可见元素、物理条件与叙事重心决定是否描写，静稳镜头允许不加；无装饰性新增天气、道具或事件，无逐镜数量指标或微动凑时长 |
| 环境微动执行（选用时） | 对象、来源、必要方向与幅度明确，速度合理；变化在当前景别可读、强度不抢主体，固定结构稳定，无机械同频摆动或无依据曝光波动；运动写“画面”，声音和真实光变各归对应字段 |
| 环境微动连续（选用时） | 同场风向、强度、烟汽来源和火焰状态相容，改变有依据；事件反馈有触发与衰减，仅在动作接切或剧情需要时衔接具体运动阶段，不强锁自然摆动相位 |
| 可执行性 | 主体清楚，动作落点可见，遮挡可解释；地标、轴线、距离、取景比例和尺度相容；长镜节拍有先后且做得完，无多人独立复杂动作同时堆叠 |
| 特殊打斗启用 | 仅原文或用户要求支持的持续近身交锋启用；普通冲突不扩编连招，结束后退出；画风与风格化效果另有依据 |
| 特殊打斗动作（仅启用时） | 攻击、格挡/命中、重心变化、恢复支撑与后续动作接续；能力、伤势、胜负、道具与环境损坏持续，时间容纳实际动作 |
| 参考方法迁移（学习/新例任务时） | 从当前目标、身体限制和空间重新设计攻防及观看重心；不能只换角色名、地点与参数后复用参考的动作/镜头顺序；忠实改编任务仍保留原事件 |
| 特殊打斗摄影（仅启用时） | 关键接触可见，必要肢体在画内；跟移/环绕/穿越路径可通行，轴线过渡明确，插入剪切另有镜号；不以特效和单人反应替代全部交锋 |
| 声音层级 | 环境、关键事件与细节声有轻重和距离；声画同步；声音跨镜连续且不重复分配整句；无依据不添音乐、对白或非语言发声 |
| 声音槽位 | 需要分层时，环境底层、关键事件声、动作拟音、对白、非语言、静音/BGM和声音桥接的取舍有依据，不为填满槽位堆声 |
| 景别 Profile | 已明确采用对话表演型、空间叙事型或动作奇观型；景别重心与项目任务一致，没有把固定比例当硬规则 |
| 参考素材 | 使用普通清单和标准资产名；不默认出现 `@[...]`、首帧锚定或未确认的素材用途 |
| 起始/结束状态 | 用文字记录人物姿态、位置、朝向、视线、手部/道具和空间地标；不依赖首帧锚定，不用“同前”代替状态 |
| 复杂度 | 已检查画中画、多人独立复杂动作、多次硬切、跨时空和参考过多；高风险镜头已拆分、降动作或明确风险 |
| 转场 | 硬切、匹配剪辑、黑场、遮挡、声音桥接或画框转场有明确因果；不把真实切镜藏在长镜中，不把一镜到底和多次硬切混写 |
| 负面约束 | 段级优先保留5–8条真正影响结果的限制；不逐镜重复同一组“不要”，不无依据增加平台或风格禁令 |
| 长文续作 | 本批范围覆盖完整、镜号连续、接续状态可恢复，新段自身信息完整 |
| 输出边界 | 默认只有段落版、固定字段、独立@；不含母版、分析和额外镜间说明 |

## 自动检查

在技能目录运行：

```text
python scripts/validate_storyboard.py 分镜文件.md
python scripts/validate_storyboard.py 分镜文件.md --start-shot 31 --start-paragraph 8
python scripts/validate_storyboard.py 分镜文件.md --check-voices
```

脚本只检查可确定的结构和数值：段与镜的连续编号、正时长、精确求和、所有段落的10.0–15.0秒范围、标题/字段、运镜中的摄影机/焦点/结束及运动词、段间分隔符、部分抽象依赖语及非法时间表达。使用 `--check-controls` 时，还会检查可选制作控制卡中的景别 Profile、参考素材禁用项、首帧锚定、群像人物层级、整桌人数相容性和9张参考图预算。使用 `--check-voices` 时，会检查含对白镜头是否有音色锚点、锚点是否为3–5项稳定描述、V-ID/角色/基础描述是否跨镜冲突，以及音色卡与锚点是否一致。它不校验三帧差异、实际声音相似度或模型是否遵循提示词，也不能验证五要素的实际完整性、原文覆盖、细节质量或路径能否执行。按上表做语义检查后才能交付。
