# 成品格式与质检

## 固定格式

每个段落按以下顺序输出；不添加独立镜间解释、导演分析或检查结果。复杂项目可在内部使用制作控制卡，但默认不把它写进交付；控制卡规则见 [制作控制与执行策略](production-controls.md)，角色音色规则见 [角色音色分析与跨镜绑定](voice-consistency.md)。

1. `段落N｜总时长：X.Xs`
2. `场景：具体地点 具体时间 内/外`
3. `出场人物：姓名、姓名`（无符合条件者写“无”）
4. `本段统一光影/质感：只描述环境和成像`
5. 逐镜重复：`镜N｜X.Xs｜景别/视角/构图`、`画面：`、`台词/声音：`、`运镜：`。
6. 有对白的发声者在 `台词/声音` 中使用 `标准资产名【V001｜基础音色描述】`；同一角色跨镜复用同一 V-ID 和同一基础描述，临时情绪写在锚点外。
7. 环境光确实变化时，允许在相应镜头“画面”后补 `本镜光影：`，不写人物。
8. 一段内真实切换地点、时间或内外景，在新镜头之前单独写 `场景：新地点 时间 内/外`。不在段首写双场景箭头，不命名“场景1到场景2”。同一连续镜头穿过同一场所的相连区域，可用具体上位场所名，在画面中按门口和路径交代区域变化；不把不连续时空冒充相连空间。
9. 两段之间用单独一行 `@`；镜号全程连续。新作品默认段落1、镜1；续作沿用已有编号。

运镜字段写法（SD 单行摄影机指令）：

```text
运镜：摄影机[起位·视角/高度·景别·距主体公制距离]看[主体]，[运动路径]；焦点[变化轨迹或稳定位置]；结束于[结束构图+停留感]
```

五要素按此顺序串成一句：起位（含位置/机高与视角/景别/距主体公制距离，停用“步”）→ 观察/跟随目标 → 运动路径（推/拉/摇/移/升/降/环绕/固定/复合九类动词之一，可带缓入缓出等速度曲线）→ 焦点变化或稳定焦点 → 结束构图（含停留感：停留/切出/静止/续作）。缺任一项应补回，不允许省略。固定机位可写“焦点稳定在具体主体”，不强制转焦；稳定焦点不是遗漏焦点字段。

用起始、变化和结束状态检查同一主体/空间锚点与连续性，输出仍为上述单行五要素。静默、等待和固定观察允许前后构图、姿态或焦点相同，不能强行制造变化。运镜字段内不放秒数、时间码、百分比、固定时间点，不写“接上个、同前、保持不变、继续推进”等抽象依赖语。镜头时长只放镜头标题。单镜时长推荐一般不低于 2.0 秒（除特殊爆点快剪外）。细节粒度和路径范例见 [描述细节与运镜设计](description-and-camera.md)。

## 合格收尾示例

示例输入：“午后书房。沈砚坐在桌后，右手按住一封信。温知予站在门内。沈砚说：‘先关门，再把这封信收好。’温知予说：‘我明白。’她关门，走到桌边。沈砚把信递给她，她接过收进袖中。”

以下示例总时长为11.3秒，符合每段10.0–15.0秒规则，单镜头时长均保持在2.0秒以上以保障 AI 视频生成可行性。该例用来说明180°轴线、屏幕视线朝向锁定、人像景别解剖切点、公制距离、动接动及五要素运镜；其中声线是演示用设计值。实际项目应先建立角色音色卡。

```text
段落1｜总时长：11.3s
场景：书房 午后 内
出场人物：沈砚、温知予
本段统一光影/质感：窗侧自然暖光，低饱和暖灰与棕褐色调，高光柔和，暗部木纹与背景织物细节清楚，环境保留浅景深使门廊结构清晰可辨，沿用项目既定画风。

镜1｜3.5s｜中景/眼高平视30°偏侧/前实后虚双人纵深构图
画面：[轴线左侧机位] 沈砚置于画面左侧三分线（裁至腰部），身体朝向门内，视线投向画右；温知予处于后景右侧门槛内。沈砚抬眼锁定温知予，眉心微蹙，右手食指在桌上信封轻点一下。
台词/声音：沈砚【V001｜成年男声·中低音·沉稳·语速适中】看着温知予说：“先关门，再把这封信收好。”温知予在后景闭口静听；窗外稀疏鸟鸣。
运镜：摄影机在书桌右前方约1.8米（与沈砚坐姿眼高齐平），看沈砚右手信封与后景温知予，沿纵深物理慢速推进（Dolly In，缓入缓出）；焦点随推进自然保持在沈砚面部与信封景深；结束于沈砚按信与温知予立于门内的中景构图，停留切出。

镜2｜2.2s｜中近景/胸高平视正侧向/右侧留白三分构图
画面：[轴线同侧反打] 温知予站在门内右侧三分线（裁至胸前），身体朝向书桌，视线投向画左（与沈砚对视）；她迎着目光轻点一下头，唇线合拢。
台词/声音：温知予【V002｜年轻女声·清亮中音·语速偏慢】看着沈砚说：“我明白。”窗外鸟鸣渐止。
运镜：摄影机在门框左侧约1.5米（与温知予立姿胸高齐平），看温知予面部，固定机位（带微幅呼吸感）；焦点稳定在温知予眼眸；结束于温知予点头后视线转向门闩的构图，切出接转身动作。

镜3｜2.8s｜中景/腰高平视微侧/门框框架式构图
画面：[承接转身动接动] 温知予仍立于门内，右手握住门把顺势将门板合拢，随即转身面向书桌，迈步走至桌前停定；沈砚坐在背景书桌后（裁至腰部），右手按住信封等待。
台词/声音：无台词；门轴轻响、门板合拢落锁声，伴随两步轻缓脚步。温知予、沈砚闭口。
运镜：摄影机在沈砚左后侧约1.8米·腰高·中景·框架式，看温知予关门与走近动线，定点慢速微摇跟随着身动线；焦点稳定在温知予行进路线；结束于温知予站定桌前、视线落于信封的双人中景构图，停稳切出。

镜4｜2.8s｜中近景/眼高平视微仰/双人过肩构图
画面：[承接递信接点] 沈砚抬眼看向桌前温知予，右手捏起信封递出；温知予右手接住信封下沿，拢开左袖将信封妥帖收入袖中，再抬眼迎向沈砚目光。
台词/声音：无台词；纸张擦过衣料的细响，室内安静。沈砚、温知予闭口。
运镜：摄影机在温知予右肩后约0.8米（眼高平视），看沈砚递信与温知予接信收信，推近一小段（缓入缓出）；焦点稳定在信封交接动作；结束于温知予拢妥袖口、二人目光重新交汇的中近景构图，停留切出。
```

## 合格快节奏与反差剪辑示例（截断剪辑与情绪换挡）

示例输入：“午后顾府客房。苏莞躺在床上，猛地弹坐抱头痛呼‘我的黄金！我的——’话音未落，门外嬷嬷一脚暴烈踹开木门大步跨入。苏莞被巨响震得倒吸冷气目瞪口呆。嬷嬷怒斥‘苏莞！十年之期已到，真小姐归来，你还不滚出顾家！’苏莞眨巴两下眼，表情瞬间从惊恐变成看疯子般的极度荒谬与怀疑人生。”

以下示例总时长为 13.2 秒，严格符合 10.0–15.0 秒规则。本例用于演示**音画截断剪辑、动静急刹对撞、写实生理应激反应、情绪瞬间换挡微表情、贴地大仰角机位与单人隔离高频正反打**的综合运用（提供镜头语言表现参考，不作为机械套用模板）：

```text
段落1｜总时长：13.2s
场景：顾府客房 午后 内
出场人物：苏莞、嬷嬷
本段统一光影/质感：午后暖光自左侧窗棂透入室内，梳妆台木纹与米灰床帐光影层次清楚，右侧木门与旧木家具明暗分明，柔和高光，暗部不压黑，沿用项目既定画风。

镜1｜2.6s｜中景/平视视角/框架构图
画面：本镜画面中仅有1人：苏莞。房内床榻居中靠墙，左侧为开敞窗棂与梳妆台，右侧为闭合木门。苏莞原本仰卧在床上，双手平放身侧。她猛然收腹弹坐而起，床垫下陷，双手抬起紧紧捂住两侧太阳穴，失神地左右抓狂晃脑；她张大嘴巴急声痛呼，珠簪剧烈震荡；喊至第二个“我的”时身形骤然被门外暴响截断。
台词/声音：苏莞【V001｜年轻女声·清润纤细·语速平缓】急声痛呼（音量高，急促尖利；尚未喊完便被暴响截断）：“我的黄金！我的——”急促喘息声、被褥猛烈摩擦声。
运镜：摄影机在床前正面微偏右·机位高度：距地约1.0米·拍摄角度：光轴水平·中景·距苏莞约1.8米，看苏莞由仰卧猛烈弹坐抱头，快推（带手持微幅呼吸感）收紧至苏莞双手抱头上半身；焦点稳定在苏莞面部；结束于苏莞双手抱头张口痛呼的三分构图，尾字截断。

镜2｜2.2s｜中全景/贴地仰视角/动作冲击构图
画面：本镜画面中仅有1人：嬷嬷。摄影机贴近房内偏左木地板，前景为低平木地坪，右侧木门紧闭。话音未落，右侧木门受门外猛烈一脚暴烈撞开砸向墙壁；嬷嬷着深色布鞋自右侧门外大步跨过门槛，双脚在门内地坪重重踏定；门板晃动，风尘轻扬。
台词/声音：无台词；门外暴烈踹门巨响，木门撞墙震天巨响，沉重布鞋踏地声；画内人闭口。
运镜：摄影机在房内偏左地坪处·机位高度：距地约0.2米·拍摄角度：贴地大仰角·中全景·距右侧木门约2.0米，看右侧木门被暴烈踹开与布鞋踏入，定点微摇顺势向右上微仰并伴随踹门震颤的手持微幅呼吸感；大景深保持门槛与跨入双脚清晰，焦点稳定在木门与地面接触区；结束于双脚重踏踩实、门板剧烈震荡的低角度构图，动作落稳。

镜3｜2.0s｜中近景/平视视角/反应切镜构图

台词/声音：无台词；短促倒吸冷气声、床板与衣料骤停微响；苏莞闭口。
运镜：摄影机在床前偏左·机位高度：距地约1.0米·拍摄角度：光轴水平·中近景·距苏莞约1.5米，看苏莞被巨响吓懵的应激微表情，固定机位（带手持轻微惊慌微颤）；焦点稳定在苏莞骤然睁圆的双眼；结束于苏莞双手扶膝、目瞪口呆的三分构图，切出。

镜4｜4.0s｜中景/贴地仰视角/压迫纵深构图
画面：本镜画面中仅有1人：嬷嬷。右侧木门内，嬷嬷身形在贴地大仰视下高耸遮挡大半门框，双手垂在身侧，脸部肌肉紧绷冷硬，三角眼倒竖，声色俱厉地对着画左方向恶狠狠输出；说完下颌紧咬，居高临下威压不退。
```

## 输出前语义质检

| 检查 | 通过条件 |
| --- | --- |
| 原文覆盖 | 每段原句、动作、台词和信息揭示都有镜头对应，无概括、删词、漏段或擅自续写 |
| 节拍 | 按意图与情绪转折，段内有推进、落点和必要反应；不是凑秒 |
| 时间 | 台词听得清、动作做得完；每段（含尾段）10.0–15.0秒；所有标题等于实际镜头之和；单镜时长推荐一般 $\ge 2.0$ 秒（极速动作除外） |
| 场景 | 段首只有起始场景；切换在对应新镜之前；地点、时间、内外完整 |
| 人物 | `出场人物`只含实际发声、关键动作或关键反应者，角色身份具体，无被提及者混入；它不等于场景在场人物 |
| 群像层级 | 同一连续场景已区分场景在场、本段入画、本段出场和画外在场；出场人物少不等于场景里只有这些人 |
| 群像入退场 | 新角色有入口、揭示或画外声音；旧角色有离场动作、画外状态或连续性锚点；人物组合变化有因果 |
| 整桌/全景可见 | 画面人数与场景在场名册相容；空座有原因，未入画人物有画外声音、道具或明确离场说明 |
| 参考图预算 | 每段最多9张：场景1张 + 角色最多8张；同一角色不同造型分别计数，其他参考也占预算，总数不超9张 |
| 状态/道具 | 坐站蹲躺、位置、朝向、持物逐镜延续；改变有动作；跨段写全 |
| 对话与轴线 | 谁对谁说明确；严格遵守 180° 轴线；画左角色视线投向画右、画右角色视线投向画左，对视锁定防撞车 |
| 角色音色 | 每个实际发声身份有唯一 V-ID；同角色没有多 ID，同 ID 没有多角色；基础描述跨镜一致 |
| 音色锚点 | 每个含对白镜头都带锚点，紧跟在标准资产名后；锚点含3–5项稳定特征，不混入临时情绪或受伤状态 |
| 音色绑定 | 角色音色卡、分镜锚点、参考音频/Voice ID/种子信息一致；缺失素材写“待配置”，不把文字锚点冒充声学锁定 |
| 嘴型 | 无台词明确标注；无口部动作时闭口；OS/旁白/听者不做他人说话口型；原文自然口部动作及非语言发声完整保留 |
| 画面与景别 | 人体截取符合解剖基准（胸/腰/膝/锁骨）；机高与倾角解耦；关键动作有触发、接触和结果；动接动出入点连贯 |
| 构图留白 | 视线前方有 Look Room；移动主体前方有 Lead Room；人像头顶有适当 Headroom；避免主体贴边撞框 |
| 运镜规范 | 一句话含起位、观察/跟随、运动、焦点、结束五要素；运动路径使用推/拉/摇/移/升/降/环绕/固定/复合九类动词起头；区分物理推与变焦；带缓入缓出等速度曲线；起位距离统一使用标准公制单位（米/厘米），全面停用“步”；无时间码；切镜以新镜号表达 |
| 光影与景深 | 自然低饱和、有来源光线、背景可辨；景深层次可控（全景深/环境浅景深/极浅景深）；字段不含人物 |
| 可执行性 | 主体清楚，动作落点可见，遮挡可解释；地标、轴线、距离、取景比例和尺度相容；长镜节拍有先后且做得完，无多人独立复杂动作同时堆叠 |
| 特殊打斗启用 | 仅原文或用户要求支持的持续近身交锋启用；普通冲突不扩编连招，结束后退出；画风与风格化效果另有依据 |
| 特殊打斗动作（仅启用时） | 攻击、格挡/命中、重心变化、恢复支撑与后续动作接续；能力、伤势、胜负、道具与环境损坏持续，时间容纳实际动作 |
| 特殊打斗摄影（仅启用时） | 关键接触可见，必要肢体在画内；跟移/环绕/穿越路径可通行，轴线过渡明确，插入剪切另有镜号；不以特效和单人反应替代全部交锋 |
| 声音层级 | 环境、关键事件与细节声有轻重和距离；声画同步；声音跨镜连续且不重复分配整句；无依据不添音乐、对白或非语言发声 |
| 声音槽位 | 需要分层时，环境底层、关键事件声、动作拟音、对白、非语言、静音/BGM和声音桥接的取舍有依据，不为填满槽位堆声 |
| 景别 Profile | 已明确采用对话表演型、空间叙事型或动作奇观型；景别重心与项目任务一致，没有把固定比例当硬规则 |
| 参考素材 | 使用普通清单和标准资产名；不默认出现 `@[...]`、首帧锚定或未确认的素材用途 |
| 起始/结束状态 | 用文字记录人物姿态、位置、朝向、视线、手部/道具和空间地标；不依赖首帧锚定，不用“同前”代替状态 |
| 复杂度 | 已检查画中画、多人独立复杂动作、多次硬切、跨时空和参考过多；高风险镜头已拆分、降动作或明确风险 |
| 转场 | 硬切、匹配剪辑、黑场、遮挡、声音桥接或画框转场有明确因果；不把真实切镜藏在长镜中，不把一镜到底和多次硬切混写 |
| 负面约束 | 段级优先保留5–8条真正影响结果的限制；不逐镜重复同一组“不要”，不无依据增加平台或风格禁令 |
| 长文续作 | 本批范围覆盖完整、镜号连续、接续状态可恢复，新段自身信息完整 |
| 输出边界 | 默认只有段落版、固定字段、独立@；不含母版、分析和额外镜间说明 |

## 自动检查

在技能目录运行：

```text
python scripts/validate_storyboard.py 分镜文件.md
python scripts/validate_storyboard.py 分镜文件.md --start-shot 31 --start-paragraph 8
python scripts/validate_storyboard.py 分镜文件.md --check-voices
```

脚本只检查可确定的结构和数值：段与镜的连续编号、正时长、精确求和、所有段落的10.0–15.0秒范围、标题/字段、运镜中的摄影机/焦点/结束及运动词、段间分隔符、部分抽象依赖语及非法时间表达。使用 `--check-controls` 时，还会检查可选制作控制卡中的景别 Profile、参考素材禁用项、首帧锚定、群像人物层级、整桌人数相容性和9张参考图预算。使用 `--check-voices` 时，会检查含对白镜头是否有音色锚点、锚点是否为3–5项稳定描述、V-ID/角色/基础描述是否跨镜冲突，以及音色卡与锚点是否一致。它不校验三帧差异、实际声音相似度或模型是否遵循提示词，也不能验证五要素的实际完整性、原文覆盖、细节质量或路径能否执行。按上表做语义检查后才能交付。
